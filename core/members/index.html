MEMBERS

회원 데이터

회원 기본정보, alias, 요약 read-model을 분리해서 동명이인과 임시 ID 문제를 줄입니다.

전환 준비

members

이름, 전화번호, 등록일, 상태, 최근 방문, 현재 수강권 요약을 담는 회원 기준 문서.

전환 준비

memberAliases

StudioMate ID, 전화번호 변경, 이름 변경, excel 임시 ID를 실제 회원으로 연결.

read-model

memberSummaries

운영자 검색과 GPT 분석을 위한 요약. 외부 발송/쓰기 원천으로는 사용하지 않음.

주의

name-only match 금지

회원 write, 알림톡, 연락처 동기화는 전화번호 또는 StudioMate ID 확인 후 진행.

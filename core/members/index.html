회원 운영 보드

회원을 찾고, 상태를 보고, 외부 실행 전에 멈춰야 할 조건을 확인합니다.

read-only

1. 검색/필터

search

이름, 회원ID, 전화번호 끝자리, 수강권명으로 빠르게 좁힙니다.

2. 상세 확인

member 360

회원 상세에서 구매, 예약, 메모, 알림톡 로그를 함께 봅니다.

3. 품질 이슈

guard

동명이인, 임시 ID, 전화번호 누락이 있으면 Imports 탭에서 원천을 먼저 확인합니다.

4. 외부 실행

stop

발송, 연락처, StudioMate write는 member360Cards가 아니라 canonical source만 사용합니다.

회원 데이터 경계

CORE 회원 화면은 판단용 read-model입니다. 원천과 실행 경계를 분리합니다.

source map

members

이름, 전화번호, 등록일, 상태, 최근 방문, 현재 수강권 요약을 담는 회원 기준 문서.

memberAliases

StudioMate ID, 전화번호 변경, 이름 변경, excel 임시 ID를 실제 회원으로 연결.

memberSummaries

운영자 검색과 GPT 분석을 위한 요약. 외부 발송/쓰기 원천으로는 사용하지 않습니다.

name-only match 금지

회원 write, 알림톡, 연락처 동기화는 전화번호 또는 StudioMate ID 확인 후 진행합니다.

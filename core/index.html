contracts
영역 컬렉션 역할 외부 액션 사용
원본 추적 sourceImports / sourceImportRows 엑셀 파일, 다운로드 시각, 정규화 결과, 원본 행 감사 불가
회원 members / memberAliases 회원 기본정보, 전화번호, StudioMate ID, 임시 ID 연결 승인 후 가능
이용 이력 memberUsageEvents / privateSessionLedger 누적 프라이빗 회차와 현재 수강권 회차 계산 읽기 우선
결제와 수강권 memberPaymentEvents / memberTickets 회원별 구매, 환불, 수강권 원장과 월별 매출 검증 운영자 승인 필요

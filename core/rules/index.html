운영 규칙

ARCHIVE CORE에서 현재 유효한 운영 기준과 실행 상태를 관리합니다.

데이터 원천 경계

보는 데이터와 실행 데이터는 의도적으로 분리합니다.

canonical first
표시/분석members, member360Cards, dashboardSnapshots는 운영자 검토와 GPT 분석용 read-model입니다.
알림톡/외부 발송alimtalkCandidates, alimtalkSends, 승인 큐와 canonical key 기준만 사용합니다.
StudioMate writeFirestore memo queue와 StudioMate 브라우저 lock을 거친 작업만 실행합니다.
연락처 동기화전화번호와 실제 StudioMate memberId가 확인된 contactSyncJobs만 사용합니다.
출석 체크인입구 iPad 체크인은 운영자 로그인과 기기 설정 없이 바로 동작하며, 오늘 예약된 bookings만 조회합니다.
operator note

CORE는 판단 콘솔

ARCHIVE CORE에서 상태를 보고 판단하되, 실제 발송/쓰기/예약/결제 관련 실행은 승인된 원천과 큐에서만 진행합니다.

canonical

외부 액션 원천

알림톡, 연락처, StudioMate write는 승인된 canonical source에서만 실행.

workLanes

임시 작업 본부

새 스레드와 실험 데이터는 workLanes에 두고, 승격 전까지 원천으로 쓰지 않음.

duplicate

운영 문서

check-in

출석·주차

회원은 휴대폰 뒤 4자리로 오늘 예약을 확인하고, 출석 처리와 2시간 주차 할인 Job은 같은 트랜잭션으로 생성.

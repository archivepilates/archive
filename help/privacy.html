공개 상담

공개 상담 GPT에는 확인된 센터 자료와 상담 주제·요일·시간대처럼 정해진 조건만 전달됩니다. 입력한 문장이나 채팅 이력은 OpenAI로 보내지 않으며, 헬프가 대화 원문을 별도로 보관하지 않습니다. API 응답 저장 기능은 사용하지 않습니다. OpenAI의 서비스 운영 및 보안 기록은 OpenAI API 데이터 안내를 참고해 주세요.

이름, 연락처, 생년월일, 주소, 건강정보와 인증번호는 공개 채팅에 입력하지 마세요. 개인 수강권과 이용내역은 공개 챗봇에서 조회하지 않습니다.

직원 문의

직원 문의는 별도의 카카오톡 채널에서 진행합니다. 헬프 화면에서 카카오톡으로 채팅 내용이나 개인정보를 자동으로 보내지 않습니다.

기존 웹 문의

이전에 접수한 문의의 성함, 연락처, 문의 내용과 처리 이력은 상담·처리 결과 확인을 위해 접수일부터 90일간 보관하며, 만료 후 기존 기준에 따라 삭제합니다. 개인정보 관련 문의는 센터 데스크에 알려 주세요.

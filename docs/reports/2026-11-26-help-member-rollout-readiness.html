스튜디오메이트 원본

20:14~20:16 KST에 회원 목록 22페이지를 읽고 재확인했다. 회원 1,067명 중 수강권 조회 후보는 176명, 발급권 200건이었다. 후보에서 소유자 증빙 누락, 횟수·이용일자 누락, 등록 연락처 누락은 없었다. 등록 번호가 있다는 사실은 번호 소유권 확인을 뜻하지 않는다.

21:49 KST에 센터가 확정한 등록 기준으로 22페이지를 다시 대조했다. 활성 등록 239명 중 수강권 후보 176명 전원이 원본 등록 시각과 유일한 현재 등록 연락처 조건을 충족했다. 이는 번호 소유 확인이나 운영 인증 완료 건수가 아니다.

배포 전 등록 기준

센터 기준상 스튜디오메이트 회원등록 완료 자체가 현장 본인확인이다. CORE 별도 확인이나 스튜디오메이트 앱 가입은 요구하지 않는다. 등록 시각과 비활성 여부를 확인하고, 현재 등록 번호가 유일한 경우만 검토한다. 휴대폰 소유는 회원이 직접 요청한 헬프 인증번호로 별도 확인한다.

11월 26일 점검 당시 운영 연락처 승인 원장은 테스트 계정 2건만 보유했다. 초기 점검은 원본이나 운영 설정을 변경하지 않았고, 회원 알림도 발송하지 않았다.

운영 연결 순서

  1. 원본 등록 완료와 활성 상태에 따라 조회 대상 명단을 만든다. 스튜디오메이트의 정확한 회원 ID와 현재 등록 연락처에 묶고, 연락처가 바뀌거나 공유 번호가 발견되면 자동 승인하지 않는다.
  2. 최초 개인 조회에만 회원이 헬프에서 인증 알림톡을 직접 요청한다. 기존 같은 상담 유지 방식과 본인 수강권만 볼 수 있는 서버 검증을 그대로 사용한다.
  3. 상품 분류를 확정하고 두 계정에서 교차 검증한 뒤, 기존 실행기의 첫 정기 발행과 원본 대조가 성공하면 확인이 끝난 회원부터 공개한다.

11월 27일 추가 확인

강사레슨 (2T) 20건과 그룹 체험권 1건을 조회 범위에서 제외한다. 스타터 패키지 그룹 6회권은 실제 그룹 수강권이므로 포함하며, 별도 OT는 합산하지 않는다. 적용 전 원본 대조 결과 일반 조회 대상은 157명이고 미분류 상품은 없었다.

두 실계정 수동 테스트는 요청에 따라 생략으로 기록했다. 오전 9:51 KST의 첫 정기 실행과 Supabase 저장 원장을 대조해 회원 157명·수강권 179건을 확인한 뒤 일반 공개를 켰다. 운영 사이트 4개 화면 크기의 인증창과 미인증 조회 차단을 확인했다. 실제 알림톡 수신은 별도 미검증이다.

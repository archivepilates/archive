LG 에어컨 API 제어

ARCHIVE CORE 운영자 메뉴 · 2026.10.21

로컬 구현 · 운영 미배포
핵심 결과

센터 에어컨 8대의 목록·프로파일·상태를 LG 공식 API에서 조회했습니다. 제어 화면과 서버 안전장치를 구현했으며 실제 에어컨 전원·온도는 변경하지 않았습니다.

기존 PAT가 도구 출력에 포함된 이력과 교체 권고를 알렸으며, 사용자는 2026.10.21 기존 PAT 사용을 선택했습니다. 원문 재출력 없이 비공개 서버용 연결 파일에만 보관합니다. 코드·Git·본 보고서에 원문을 포함하지 않았으며 Secret Manager 등록·배포는 하지 않았습니다.

구현 범위

구분구현 내용
메뉴에어컨 상태, 현재·희망 온도, 습도, 전원, 운전 모드, 바람 세기, 지원 기기의 상하·좌우 바람과 절전.
권한기존 활성 owner·manager와 세션 유효성을 매 callable에서 확인. 강사·미로그인·권한 철회 계정은 토큰 조회 전에 차단.
비밀정보서버 전용 LG_THINQ_CONNECTION_JSON. PAT·고정 clientId·정확한 기기 허용 목록·제어 활성 여부를 보관. 브라우저 입력·저장 기능 없음.
지원 기능LG 프로파일의 쓰기 권한·허용값·범위·단위를 기준으로 구성. 동적 운전 모드별 온도 범위 검증. 센터 현재 8대의 일반 온도 범위는 16~30°C, 0.5°C 단위.
변경 전 확인허용 기기 여부, 최신 목록·프로파일·상태, 화면 이후 제어값 변경 여부를 재검증. 임의 API 주소·속성·JSON 전송 차단.
결과요청 접수·상태 일치 확인·거절·결과 미확인을 구분. 상태 일치는 조회값의 일치 증거이며 기기 동작의 인과적·물리적 보장은 아님.

실행 구조

CORE 권한 확인 → 기기 잠금·명령 원장 → LG 원본 재조회 → 유효성 확인 → 제어 1회 → 상태 재조회

  • 명령 UUID와 요청·사용자 지문으로 같은 명령을 다시 보내지 않습니다. 기기별 동시 제어는 거래식 잠금으로 차단합니다.
  • 실행 전 60초 기한과 잠금 소유권을 다시 검증합니다. 응답 불명확·상태 지연은 잠금을 유지하며 자동 재전송하지 않습니다.
  • 원본 요청이 실행 중일 수 있는 첫 120초에는 잠금 해제를 허용하지 않습니다. 이후 상태 일치로 확인하거나 운영자가 조회된 현재 상태를 명시적으로 확인해야 해제합니다.
  • 목록·프로파일만 화면 조회용으로 최대 10분 캐시합니다. 상태는 매번 조회하며 실제 변경은 모두 새 조회를 사용합니다. 새 정기 실행·MQTT 구독·전체 켜기는 추가하지 않았습니다. 사용자 요청으로 전체 끄기만 기존 기기별 검증 경로에 연결했습니다.
  • 조회는 사용자당 최소 10초 간격, 기기는 최대 2대 동시 조회, 개별 HTTP 8초 제한입니다. 한 기기 조회 실패는 다른 기기까지 숨기지 않습니다.

검증

  • 서버 정책·중복·동시 실행·온도 범위·장애·지연·원장 실패·재확인 합성 테스트 38건 통과.
  • 실제 권한 가드와 거래식 저장 로직의 격리 테스트 13건 통과. 서비스 계정·운영 Firestore·LG 제어 API에 접속하지 않는 모의 의존성 시험.
  • 기존 메뉴·업무·알림톡 카탈로그 회귀 52건, 강사·프라이빗 접근 회귀 224건 통과.
  • 5개 Functions 코드베이스 빌드 및 소유권 검사 통과. 공유 배포 감지 규칙이 모든 코드베이스를 영향 대상으로 표시하지만 새 실행 함수는 functions-app 소유입니다. 실제 배포 범위는 릴리스 시 재검토합니다.
  • UI 테스트 26건 통과. 실제 app.js 인증 후 초기화·일반 회원 데이터 미조회·계정 변경 및 로그아웃 중 응답 무시·동일 명령 유지·미확인 잠금을 검증했습니다. 320·390·768·1440px 캡처에서 가로 넘침·문구 잘림·44px 터치 영역·포커스 검사를 통과했습니다. CUA 브라우저에서도 로컬 가상 기기의 24→24.5°C 입력과 화면 갱신을 확인했습니다.

ThinQ 모바일 디자인

사용자가 첨부한 LG ThinQ 모바일 화면을 참고해 꺼진 기기는 회색 카드, 운전 중인 기기는 흰색 카드로 정리했습니다. 기기별 전원 아이콘과 실내·희망 온도를 우선 표시하고, 온도는 기기 프로파일의 단위로 조절합니다. 운전모드·풍량·풍향·절전은 상세 설정에 모았습니다. 지원하지 않는 전체 제어·기기 추가·알림·하단 탭은 흉내 내지 않았습니다.

개선 화면의 합성 브라우저 테스트는 47건 모두 통과했습니다. 320·390·768·1440px에서 켜짐·꺼짐 혼합 카드, 상세 설정 접힘·펼침, 읽기 전용 상태를 촬영하고 가로 넘침·온도 숫자 잘림·44px 터치 영역·포커스를 검사했습니다. 최초 발견한 작은 화면의 온도 숫자 넘침은 칸 너비와 글자 크기를 보완한 뒤 재검증했습니다. 0.1·0.5·1°C 증감 단위, 경계값 차단, 응답 전 값 불변, 처리 중 상세 열림 유지도 통과했습니다. CUA 로컬 가상 기기의 24→23.5°C 조절 결과를 확인했습니다. 실제 기기는 제어하지 않았습니다.

추가 메뉴·모션 회귀 15건과 Hosting 검사는 통과했습니다. 과거 UI-only 전용 검사는 23건 통과·4건 실패했습니다. 이번에 변경하지 않은 자동화·알림톡 페이지의 기존 스타일 순서 검사 2건, 의도적인 서버 기능·초기화 추가를 금지하는 과거 작업 범위 검사 2건입니다. 해당 검사를 완화하지 않았으며 배포 전 적용 범위 검토가 필요합니다. 전체 테스트 통과 또는 릴리스 완료로 해석하지 않습니다.

8대 표시·전체 끄기

로컬 미리보기의 가상 기기를 4대에서 8대로 늘렸습니다. 실제 기기 8대의 원본 조회 증거와 합성 미리보기는 별개입니다. 상세 설정을 열기 전에는 이름 두 줄과 온도 영역을 공통 크기로 확보해 카드 높이를 통일하고, 펼치면 내용에 맞게 늘어납니다.

아카이브 에어컨 전체 끄기는 대상 이름·개수를 확인받고 기기별 명령을 순서대로 실행합니다. 이미 꺼진 기기도 서버 원본을 재확인하되 불필요한 LG 제어 요청은 보내지 않습니다. 잠금·오프라인·지원 미확인 기기는 건너뜁니다. 명령별 기존 UUID·선점·최신 상태 검증을 그대로 사용하며 결과 미확인은 재전송하지 않습니다. 로그아웃·화면 종료 시 나머지 작업은 중단되며 자동 재개하지 않습니다. 성공·일부 실패를 구분해 기기별 결과를 표시합니다.

후속 UI·브라우저 53건과 서버 51건을 통과했습니다. 320·390·768·1440px에서 8대 혼합 상태 카드의 동일 높이, 상세 펼침, 넘침 없는 화면을 검사했습니다. 취소·순차 실행·중복 클릭 차단·부분 오류·계정 변경 중단을 합성 자료로 검증했으며 실제 전체 끄기는 실행하지 않았습니다.

메뉴 교체

영상 시청의 사이드바·업무 검색·메뉴명 검색 항목을 제거하고 에어컨 메뉴와 전용 아이콘을 연결했습니다. 기존 영상 페이지·시청 기록·수집은 보존합니다. 운영자 전용 에어컨 권한과 강사 프라이빗·시퀀스 노트 메뉴는 유지합니다. 후속 UI·브라우저 48건, 메뉴·모션·카탈로그·운영 화면 회귀 59건과 Hosting 검사를 통과했습니다. 로컬 CUA에서도 영상 시청 없이 에어컨 메뉴가 표시되는 것을 확인했습니다. 운영 배포는 하지 않았습니다.

남은 작업

  1. 사용자가 유지하기로 한 기존 PAT와 정확한 기기 허용 목록을 서버 전용으로 보안 등록합니다. 원문은 채팅·화면·로그에 표시하지 않습니다.
  2. 승인된 범위로 Firebase 프로젝트 archive-pilates의 Secret Manager 등록, CORE Hosting·해당 Functions 배포·라이브 권한 검사·커밋·푸시를 진행합니다.
  3. 사용자가 지정한 기기 1대로 실제 제어와 상태 재확인을 검증합니다. 구현·합성 테스트 통과만으로 실기 제어 완료를 주장하지 않습니다.

로컬 화면 미리보기는 합성 기기 전용이며 실제 에어컨을 제어하지 않습니다.

공식 근거

LG ThinQ Connect API 명세의 PAT·지역 URL·Device API·프로파일·조건부 제어를 확인했습니다. PAT의 개인 사용 조건을 준수하며 외부 서비스·다중 고객용 확장은 LG의 허용 범위를 별도 확인해야 합니다.

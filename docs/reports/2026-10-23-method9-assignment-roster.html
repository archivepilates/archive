METHOD #9 수업배정 명단 보완

결론

이전 수업배정 페이지에 시간표만 있고 명단이 없었습니다. StudioMate에 이미 예약된 반을 확인해 날짜별 팀 명단을 추가합니다. 운영자는 이번 양일의 전체 이름 공개를 명시적으로 승인했습니다. 휴대폰번호·수강권·취소 이력과 원본 Excel은 공개하거나 Git에 넣지 않습니다.

원본 대조

수정 범위

양일 assignment 페이지의 첫 섹션에 팀별 전체 이름과 인원을 한 번씩 표시합니다. 같은 페이지 아래 두 세션 시간표와 기구 교차 순서는 유지합니다. 기존 알림톡의 버튼 URL·템플릿·본문·주차 링크는 변경하지 않으며 알림톡을 추가 발송하지 않습니다. 교재의 수업 당일 정오 공개 게이트도 변경하지 않습니다. CORE 운영규칙에는 이번 명단의 원천·공개 승인·검증 범위를 기록합니다.

기존 업로드 확인

제목·설명·태그 저장 후 각 영상 편집 화면을 다시 열어 확인했습니다. 바렐 설명의 D팀 오류를 E팀으로 수정했습니다. 기존 비판매 재생목록은 유지했습니다.

일부공개는 링크를 가진 사람이 볼 수 있습니다. 전체공개로 전환하거나 새 영상을 업로드하지 않았습니다.

홈페이지 준비

  • E팀 전용 그룹 생성 및 0명 재조회. 기존 회원 권한 변경 없음.
  • 두 영상을 담은 숨김·검색 차단 페이지 초안 저장. 새 E팀 그룹만 접근 대상으로 설정.
  • 관리자 미리보기에서 두 영상 실제 재생과 한국어 자막 활성화 확인.
  • 320·390·768·1440px에서 가로 넘침 없음. 모바일 1열·큰 화면 2열.

게시 전 관리자 미리보기이며, 수강생 로그인으로 접근 가능한 상태라고 확인한 것은 아닙니다.

공개 전 확인

  1. 홈페이지 계정 미확인 3명 확인.
  2. 내 강의실 목록 연결 및 시청 종료·권한 회수 방식 확인.
  3. 기존 권한을 보존한 대상자 그룹 적용, 해당 페이지 게시.
  4. 권한 회원·무권한 회원·로그아웃 상태의 접근 및 모바일 재생 검증.
  5. 검증 후 수강생 안내 발송.

시청 분석은 아직 새 경로에 적용하지 않았습니다. 전체 자막 교정·일본어 메타데이터 추가도 이번 준비 범위에는 포함하지 않았습니다.

안내 예약과 가입 후 권한

사용자 추가 요청으로 10월 18일 오전 10시 제작 완료·홈페이지 가입 필요 안내 작업을 한 번 예약했습니다. 발송 채널은 선택 대기이며 선택 없이 추정 발송하지 않습니다. 이는 실행 작업 예약이며 실제 메시지 전송 완료는 아닙니다.

이후 매일 10:30·14:30·18:30에 가입 여부를 확인해 출석 원천의 이름·전화번호와 정확히 일치한 계정에만 기존 권한을 보존하여 전용 그룹을 추가하도록 후속 작업을 등록했습니다. 전원 권한·실제 접근 검증이 끝나면 종료합니다. 변동 없을 때는 별도 알림을 보내지 않습니다.

10월 18일 즉시 그룹 부여

사용자의 추가 요청에 따라 기존 가입 확인 2명의 최신 회원 상세를 재조회하고, 전용 E팀 그룹만 추가했습니다. 회원 상세와 그룹 명단을 독립 재조회해 총 2명 반영을 확인했습니다. 기존 소속 그룹·등급·회원 기본정보·포인트·쿠폰은 유지했습니다.

이는 그룹 저장 검증입니다. 페이지 게시·내 강의실 연결·권한 일반회원 실제 재생은 아직 완료되지 않았으므로 즉시 시청 가능한 상태로 보고하지 않습니다. 후속 점검은 이미 적용된 그룹을 중복 추가하지 않습니다.

10월 18일 내 강의실 점검

새 E팀 목록은 아직 표시되지 않습니다.

라이브 내 강의실은 기존 42개 수업을 표시했으며 새 E팀 링크는 0개였습니다. E팀 페이지는 관리자 미리보기에서만 열렸고, 미리보기를 종료한 뒤 직접 접속하면 홈으로 이동했습니다. 그룹 부여만으로 실제 시청 준비가 끝난 것은 아닙니다.

관리자 세션의 목록 원천은 manual이므로 일반회원 검증 증거가 아닙니다. 모바일 크기 요청도 실제 1280px 측정에 반영되지 않아 모바일 검증 완료로 보지 않습니다. 페이지 게시·목록 연결 후 일반 권한/무권한 회원으로 모바일·PC 시청을 다시 검증해야 합니다. 이번 점검에서는 사이트를 게시하거나 회원 권한을 변경하지 않았습니다.

기록과 변경 범위

위젯 소스, 준비 기록, 이 보고서 및 CORE 운영규칙 소스의 준비 상태를 변경하고 별도 예약 자동화 두 개를 등록했습니다. 10월 18일 추가 승인한 두 회원의 E팀 그룹만 변경했습니다. Firebase 배포·사이트 전체 게시·Git 커밋·푸시는 실행하지 않았습니다. CORE 실사이트 갱신도 미배포 상태입니다.

StudioMate 수업·출석, 판매상품·가격·기존 구매 권한, 다른 회원 그룹은 변경하지 않았습니다.

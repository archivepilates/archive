수정한 내용

  • ARCHIVE CORE 회원 목록과 재등록 후보는 member360Cards에 최신 memberProfiles를 오버레이해서 계산합니다.
  • 회원 상세 화면은 memberProfiles/{memberId}를 직접 읽고, 활성 수강권 배열이 빈 배열이면 과거 미러 수강권으로 되살리지 않습니다.
  • 구매이력 화면의 금액 매핑을 amountTotal/paymentDate까지 포함하도록 고쳤습니다.
  • 회원목록 Excel import가 활성 수강권에 paymentAmount, paymentAt, paymentMethod를 보존하도록 보강했습니다.
  • 최신 회원목록 회원목록_20260711_1259.xlsx를 다시 받아 Firestore에 반영했습니다.
  • 경량 reconcile로 member360Cards, members, summary/current, 현재 수강권 구매 문서를 보정했습니다.
  • npm run audit:archive-core-data read-only 검증 스크립트를 추가했습니다.
  • 배포/롤백 가드에 최신 회원 프로필 오버레이와 CORE 데이터 검증 마커를 추가했습니다.

발송 직전 StudioMate 원본으로 계산

운영자 승인 단건 실행기를 최신 수강권 재조회 방식으로 수정했습니다. 전체 회원 자동발송은 아직 비활성입니다. 이번 검증에서는 실제 알림톡을 추가 발송하거나 회원·수강권·정지 정보를 변경하지 않았습니다.

확정한 흐름

  1. 기존 시간별 회원 Excel에서 정지명단 변화를 감지합니다. 명단은 조회 참고정보이며 발송 원천이 아닙니다.
  2. 발송을 승인한 회원의 실제 수강권을 다시 엽니다. 최초 발급기간, 최신 정지 목록, 저장된 현재 정지 날짜칸을 대조합니다.
  3. 최초 기간 20%의 소수점을 버려 총 가능일을 계산하고, 원본의 실제 적용기간과 이번·예정 정지를 양 끝날 포함 날짜 합집합으로 합산합니다.
  4. 승인 내용·현재 회원·스텝 제외·템플릿·발송 원장을 재검증하고 같은 정지인지 확인한 후 1회만 발송합니다.
  5. 생성 이력 식별자, 계산 결과, 승인·메시지 ID·중복방지 기록만 남깁니다. 별도 누적 잔액과 전체 정지 원본을 반복 저장하지 않습니다.

계산 모드는 live_studiomate_readback입니다. autoSendEnabled=false와 canonicalSourcePromoted=false는 유지합니다. 이전 Firestore 정지 장부 기반 자동 큐는 사용하지 않습니다. 과거 발송·선점 감사 기록도 삭제하지 않습니다.

07 니티도

검증 결과

  • 공개 페이지 미리보기: 5개 경로 × 320·390·768·1440px, 총 20개 조합 확인. 가로 넘침과 새 페이지 오류 없음.
  • 영상 필터와 니티도 필터, 결과 없음, 초기화, 상품 목록 이동 및 해당 영상의 미리보기 일치 확인.
  • 일반 테스트회원 기준: 모바일·PC에서 권한 보유자는 예상한 6개, 미보유자는 0개 카드. 보호 페이지 접근 24개 조건 확인. 임시 테스트 그룹은 원복 후 API로 확인.
  • 내 강의실 소스는 기존 배포 기준과 동일. 배포 후 파일 해시 및 비로그인 접근 제한 검사 통과.
  • 공식홈 라이브: 원본 HTML·신규 자산 해시 일치, 커뮤니티 경로 3개 모두 302 연결 확인. 4개 화면 폭 캡처 확인.

일반회원 검증은 현재 서비스 기준 검사입니다. 아임웹 개선 코드 저장 후 공개 페이지와 일반회원 검증을 다시 진행해야 최종 완료입니다. 실제 결제·환불·영상 재생은 실행하지 않았습니다.

기존 아임웹 header_more_menu.js에서 일부 PC 화면 진입 시 발생하던 메뉴 계산 오류는 별도 경고로 기록했습니다. 권한 검사 결과와는 구분하며, 이번 코드로 새로 발생한 오류로 분류하지 않았습니다.

남은 작업

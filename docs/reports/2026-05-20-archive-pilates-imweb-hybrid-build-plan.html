Imweb Hybrid Build Plan

ARCHIVE PILATES 웹사이트 하이브리드 제작 계획

아임웹 기본 위젯은 운영, 결제, 회원 기능을 맡기고 코드 위젯은 브랜드 랜딩 경험만 담당한다. 목표는 강사레슨 대상자가 오프라인/온라인 클래스를 빠르게 이해하고 상품 상세 또는 상담으로 이동하는 구조다.

최종 원칙

Native

아임웹 기능 우선

메뉴, 로그인, 회원가입, 상품, 결제, 게시판, 푸터, SEO는 아임웹 위젯으로 관리한다.

Code

브랜드 경험만 코드

히어로, 강사레슨 카드, 후기 흐름, 채널 섹션, FAQ 애니메이션처럼 일반 위젯으로 어려운 부분만 코드로 만든다.

Sales

신청/구매 흐름 중심

오프라인 CTA는 예약 신청 또는 일정 조율 폼으로, 온라인 CTA는 상품 상세로 이동한다. 카카오 상담은 빠른 질문 채널로 둔다.

페이지/메뉴 구조

홈

코드 위젯 랜딩을 첫 화면에 배치. 핵심 CTA는 오프라인 클래스 보기, 온라인 클래스 보기.

오프라인 강사레슨

아임웹 상품 상세 페이지. 가격, 대상, 진행 방식, 일정, 환불/변경 기준을 명확히 작성.

온라인 클래스

아임웹 상품 상세 페이지. 주문 후 수강 안내, 유튜브 비공개 영상 제공 방식, 이메일 확인 절차를 작성.

후기

초기에는 홈 코드 섹션. 후기가 쌓이면 게시판 위젯으로 별도 메뉴화.

채널

인스타그램, 유튜브, 블로그. 강사레슨 대상자가 수업 언어를 확인하는 보조 전환 구간.

오프라인 예약 신청

아임웹 입력폼 위젯. 희망 일정과 레슨 목적을 받은 뒤 카카오 채널 또는 문자로 확정한다. 실시간 시간표 예약이 필요해지면 네이버 예약 또는 별도 예약 솔루션을 연결한다.

사용할 코드 위젯

사용 파일: /Users/archivepilates/Desktop/archive-pilates-imweb-benchmark/archive-pilates-hybrid-landing-widget.html

  • 아임웹 코드 위젯 하나에 전체 붙여넣기.
  • 상단 헤더, 로그인, 회원가입, 푸터를 포함하지 않는다.
  • 현재 CTA는 /shop_view/1, /shop_view/2로 연결된다.
  • 유튜브 링크는 https://www.youtube.com/@archivepilates로 연결한다.
  • 인스타그램 링크는 https://www.instagram.com/minjin.vibe/로 연결한다.
  • 카카오 상담 링크는 http://pf.kakao.com/_AHdvn/chat로 연결한다.

작업 순서

  1. 아임웹 디자인 모드에서 기본 헤더를 먼저 정리한다. 로고, 메뉴, 모바일 메뉴, 로그인, 회원가입을 켠다.
  2. 홈 첫 섹션에 코드 위젯을 만들고 archive-pilates-hybrid-landing-widget.html 전체를 붙여넣는다.
  3. 기존 임시 코드 섹션이나 숨겨둔 섹션은 삭제한다. 숨김 CSS로 오래 유지하지 않는다.
  4. 쇼핑 관리에서 /shop_view/1 상품을 오프라인 강사레슨으로 바꾼다.
  5. 쇼핑 관리에서 /shop_view/2 상품을 온라인 클래스로 바꾼다.
  6. 오프라인 예약 신청 섹션은 아임웹 입력폼 위젯으로 만든다. 항목은 이름, 연락처, 강사/예비강사 여부, 희망 레슨 형태, 희망 요일/시간대, 문의 내용으로 둔다.
  7. 푸터에 주소, 소셜 링크, 블로그 링크를 넣는다.
  8. 모바일 미리보기에서 헤더, CTA, 상품 상세 이동, 글자 겹침을 확인한다.
  9. 게시 후 실제 URL에서 오프라인/온라인 CTA와 로그인/회원가입을 한 번씩 확인한다.

아임웹 예약 기능은 숙박형 예약에 가까워 시간 단위 강사레슨에는 부적합하다. 초기에는 입력폼과 카카오 채널로 예약 신청을 받고, 필요하면 네이버 예약 등 외부 예약 솔루션을 연결한다.

Assets

실제 사진

현재 이미지는 임시 외부 이미지다. 스튜디오, 레슨, 온라인 클래스 썸네일로 교체하면 완성도가 올라간다.

최종 확인 체크리스트

  • 모바일에서 왼쪽 메뉴가 보인다.
  • 로그인과 회원가입이 아임웹 기본 기능으로 작동한다.
  • 오프라인 CTA가 오프라인 강사레슨 예약 신청 섹션으로 이동한다.
  • 온라인 CTA가 온라인 클래스 상품으로 이동한다.
  • 오프라인 예약 신청 폼에서 이름, 연락처, 희망 일정, 문의 내용이 정상 접수된다.
  • 중간 섹션에 ARCHIVE IN, 채용, 일반회원 수업 안내가 노출되지 않는다.
  • 콘텐츠 채널은 Instagram, YouTube, Blog 중심으로 보인다.
  • 주소는 부산 강서구 명지로 표기된다.
  • 푸터는 아임웹 기본 푸터로 관리된다.

이 계획은 사용자가 직접 아임웹에서 작업하는 것을 전제로 한다. Codex는 브라우저 조작 없이 코드 파일, 링크 구조, 위젯 사용 계획, 점검표를 제공한다.

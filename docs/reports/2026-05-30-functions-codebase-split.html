결론

Firebase Functions를 단일 default codebase에서 네 개의 물리 codebase로 분리하고 배포까지 완료했다.

4알림톡 함수
13프라이빗 차트/설문 함수
12동기화 함수
9앱 callable 함수

적용 내용

  • firebase/function-codebases/alimtalk, private-chart, sync, app source를 추가했다.
  • firebase.json의 Functions 설정을 네 codebase로 분리했다.
  • scripts/prepare-functions-codebase.mjs를 추가해 predeploy 때 현재 repo 기준으로 source를 생성한다.
  • scripts/validate-functions-boundaries.mjs가 Firebase 설정, manifest, compiled export 수를 함께 검증하도록 확장했다.
  • 절대 worktree 경로에 의존하지 않도록 생성 기준을 repo root와 RESOURCE_DIR로 통일했다.

검증

  • npm run build:function-codebases 통과.
  • npm run validate:function-boundaries 통과.
  • Firebase Functions dry-run 통과.
  • 네 codebase 순차 배포 통과.
  • functions:list 기준 총 38개 함수가 네 codebase로 분리된 것을 확인했다.
  • /api/privateLessonReport는 토큰 없음 400, /s/not-existing-codebase-check는 404로 함수 도달을 확인했다.

운영 기록

원인

저장 확인이 모든 iframe을 검사하여 다른 출처의 로그인 보조 프레임 접근 오류를 시퀀스 저장 실패로 처리했습니다. 격리된 로그인 보조 프레임을 추가한 WebKit 화면에서 사용자에게 표시된 동일 문구를 재현했습니다.

수정 범위

실제 시퀀스 편집기와 CORE 내용 프레임만 저장 검사합니다. 실제 저장 실패·충돌·편집기 준비 미완료 시에는 현재 기록을 유지하며 이동을 막습니다. 로그인 권한·기존 시퀀스·회원 데이터·알림톡·Functions·Firestore 설정은 변경하지 않았습니다.

  • CORE Hosting 및 라이브 롤백 방지 검사 통과

인증과 Firestore는 합성 테스트입니다. 실제 강사 로그인·실제 iPhone 검증·실데이터 저장 증거는 아닙니다.

항목변경유지·제한
1. Firestore 읽기활성 수업 ID가 없는 강사 화면 재생성에서 버려지는 예약 조회를 생략. Instagram은 실행 시각 조건을 조회 단계에 적용.취소·변경 검증용 전체 예약 기간 조회 유지. 전체 읽기 증가를 모두 해결한 것은 아닙니다.
2. 중지 자원이미 PAUSED인 API 쓰기·일일 대시보드·출석 리마인더 Scheduler와 함수 3개 제거. 관제는 명시된 대상의 404만 정상 종료로 인정.과거 큐 이력·수동 경로 유지. 권한 오류·통신 오류는 삭제 성공으로 보지 않습니다.
3. 빈 반복 처리기존 Google 설문 시트의 Drive 버전이 같으면 본문을 읽지 않음. 변경·조회 실패·24시간 경과 시 전체 확인. 게시 작업은 임대와 실행 시각 재검증.10분 주기 유지. 완전한 이벤트 기반 전환은 아니며 빈 쿼리 최소 읽기는 남습니다.
4. 비밀정보 연결38개 함수의 확인된 의존성을 반영하여 연결 378개 순감소. 누락된 퀴즈 Sheets·리포트 HMAC 연결 2건도 보완.Secret 자체와 저장 버전은 삭제하지 않음. 연결 감소는 저장 요금 감소와 다릅니다.

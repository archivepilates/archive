`studiomate-reservation-deadline`은 월요일 12:30 작업이며, 2026-05-25 12:30 err log와 종료코드 1이 있습니다.
3. Caddy 중복 정리 완료
사용자 `homebrew.mxcl.caddy` 자동실행은 제거했고, 시스템 `com.archive.caddy`만 운영용으로 유지됩니다.

원천 확인 명령: launchctl list, launchctl print gui/501/..., launchctl print system/com.archive.caddy, plutil -convert json, crontab -l, brew services list, lsof -nP -iTCP -sTCP:LISTEN, find ~/.codex/automations.

민감정보 처리: `launchctl print`에 노출될 수 있는 토큰, credential 파일 내용, Authorization 값은 대시보드에 싣지 않았습니다.

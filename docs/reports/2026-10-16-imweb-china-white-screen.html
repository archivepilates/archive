ARCHIVE PILATES 중국 접속 점검

2026-10-16 · 아임웹 중국 흰 화면 점검 채팅

부분 조치. 중국 현지 해결 확인 전. 사용자 보고: 같은 환경에서 3월에는 접속 가능, 현재 공식 홈페이지는 열리지만 아임웹 홈과 영상목록은 흰 화면.

확인한 사실

  • 운영 계정 home@archivepilates.com. 국가별·IP 차단 꺼짐, 중국 내 접속 허용 켜짐. 이 설정은 변경하지 않음.
  • WebSitePulse 상하이 검사: 아임웹 홈 HTTP 200, 3.422초. CORE 시청기록 파일 HTTP 200, 6.513초. 아임웹 jQuery HTTP 200, 0.978초. 단일 지역의 HTTP 검사이며 실제 브라우저 렌더링 검증은 아님.
  • 니티도 이미지 코드는 HEAD, 시청기록 코드는 콘텐츠 앞 BODY에서 동기 외부 스크립트로 연결됨. 느린 연결 시 문서 파싱을 지연시킬 구조는 확인했으나 중국 장애의 단일 원인으로 입증되지는 않음.
  • Git 기록: 2026-08-26 시청기록 외부 파일 연결 추가(664fb075). 운영 반영 시점과 중국 장애 발생 시점은 별도 확인 필요. 버전 이름만으로 배포 날짜를 추정하지 않음.

적용 및 미적용

  • 적용: SEO 공통 Header Code의 니티도 이미지 태그에 async만 추가. 저장 후 독립 재조회에서 다른 코드 전체 보존과 6글자 추가 확인.
  • 로컬 소스: 시청기록 로더 생성기를 async로 변경하고, 정확한 태그만 바꾸는 검사·멱등성·중복/변경 거부·CLI 제한 회귀 테스트 추가.
  • 미적용: 기존 unit/body 시청기록 태그. CLI가 본문을 936건으로 계산해 50건 제한으로 변경을 거부함. 독립 조회에서 기존 태그가 그대로임을 확인. 본문 압축, 분할, 안전 제한 우회는 하지 않음.
  • 보존: 상품·가격·회원·구매자 접근권한·실제 영상·시청기록 로직·다른 스크립트. Firebase Functions와 Hosting은 배포하지 않음.
  • CORE 운영규칙: 같은 변경·검증·보류 상태를 소스에 기록. CORE Hosting 반영은 별도 보류.

검증과 다음 확인

집중 Node 회귀 테스트 16개 통과, CLI 사전검증, 저장된 공통 코드 독립 재조회 및 공개 HTML 검사. 최초 테스트의 작업영역 의존성 누락은 기존 설치 의존성 연결 후 해결함. 국내 브라우저에서 홈과 영상목록 표시를 확인했으나, 화면 크기 변경 기능이 실제 1280px에 고정되어 320·390·768·1440px별 검증은 완료하지 못함. 중국 모바일 검증과 별도 상태로 유지함.

시청기록 async 적용 전 추가 조건: 로그인 회원 식별값 MEMBER_HASH의 초기화 순서를 확인해야 함. 현재 추적기는 값을 한 번만 읽으므로 초기화가 늦는 환경에서는 기록이 빠질 수 있음. 이 순서와 실제 시청기록 검증 전에는 로컬 생성기 변경을 추적 기능 검증 완료로 취급하지 않음.

다음: 중국 휴대폰의 새로 연 홈·영상목록 확인. 계속 흰 화면이면 도시·통신망·브라우저·오류 화면과 실패한 요청을 확보해 아임웹에 필수 리소스·초기화 실패 점검 요청. unit/body의 공식 편집 경로와 CLI 안전 제한 문제도 확인 필요. 중국 영상 재생 가능 여부는 사이트 표시와 별도이며 이번 점검으로 보장하지 않음.

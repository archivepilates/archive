  • 상품 1번 `[오프라인] ARCHIVE METHOD 5:1 강사레슨`은 `오프라인 클래스` 카테고리에 배정했습니다.
  • 상품 2번과 영상별 상품 3-22번은 `온라인 클래스` 카테고리에 배정했습니다.
  • 아임웹 디자인 모드에서 카테고리별 쇼핑 페이지를 만들고 게시했습니다.
  • 온라인 클래스 페이지: https://archivepilates.imweb.me/17
  • 오프라인 클래스 페이지: https://archivepilates.imweb.me/18
공개 검증 결과 `/17`은 온라인 상품만, `/18`은 오프라인 상품만 노출됩니다. 단, 홈 히어로 CTA의 원본 HTML 링크는 아직 기존 상품 상세 URL을 가리키므로 다음 편집에서 `/18`, `/17`로 교체해야 합니다.

회원그룹 이용권 결제 완료 시 설정한 기간 동안 지정 그룹에 속하고, 그 그룹만 허용된 콘텐츠를 볼 수 있습니다. 온라인 영상 판매의 1순위. 40일 시청권 설계와 잘 맞습니다.
디지털 다운로드 상품 파일 업로드 후 다운로드 기간과 횟수를 제한할 수 있습니다. 배송 단계는 생략됩니다. PDF, ZIP, 파일 판매에는 적합하지만 YouTube 임베드 권한 판매에는 주력 방식으로 부적합합니다.
일반 상품 + 수동 권한 일반 상품은 결제와 상세페이지 구성은 쉽지만, 콘텐츠 접근 권한은 별도 운영이 필요합니다. 초기 테스트용은 가능하지만 주문 누락/수동 처리 위험이 있습니다.
외부 권한 앱 아임웹 API는 상품과 주문 연동에 쓸 수 있으나 사이트 디자인/메뉴 전체 제어 API는 제한적입니다. 영상 수가 많아지면 Firebase 권한 앱을 붙이는 장기 구조가 더 안전합니다.

추천 구현안

1차 MVP

  1. 영상별 상품을 `회원그룹 이용권`으로 전환합니다.
  2. 각 상품에 `subscribe_group_code`와 `subscribe_period=40`을 연결합니다.
  3. 영상별 보호 페이지 또는 게시판 글을 만들고, 해당 회원그룹만 열람 가능하게 설정합니다.
  4. 상품 상세에는 공개 미리보기 YouTube 임베드와 캡처, 구매 안내만 노출합니다.
  5. 구매자는 로그인 후 마이페이지 또는 전용 메뉴에서 구매한 영상 페이지로 들어갑니다.

확장안

  1. 아임웹은 결제와 상품 진열만 담당합니다.
  2. 주문 완료 웹훅/API를 Firebase로 받아 `memberId + videoId + expiresAt` 권한을 생성합니다.
  3. `watch.archivepilates.com` 같은 보호 영상 앱에서 로그인 사용자 권한을 확인하고 임베드 영상을 보여줍니다.
  4. 영상이 20개에서 100개 이상으로 늘면 이 구조가 그룹/페이지 관리 부담을 크게 줄입니다.

운영 주의점

  • YouTube 일부공개/비공개 URL은 완전한 DRM이 아닙니다. 아임웹 보호 페이지는 접근 제어이고, 화면 녹화나 링크 공유를 기술적으로 완전히 막지는 못합니다.
  • 회원그룹을 영상별로 만들면 가장 명확하지만 관리량이 늘어납니다. 영상 묶음 상품은 관리량은 줄지만 개별 구매 권한이 흐려집니다.
  • 현재 숨김 처리된 영상별 상품 3-22번은 권한/보호 페이지가 연결되기 전까지 `nosale` 유지가 안전합니다.
  • 홈 CTA는 다음 편집에서 `/18`, `/17`로 바꿔야 메인 선택 흐름이 완전히 카테고리형으로 연결됩니다.

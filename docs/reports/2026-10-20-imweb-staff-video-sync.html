실제 권한 보완 확인 · 5분 주기 백그라운드 배포 확인

결론

쇼핑 등급은 할인에만 연결돼 있었고 영상 자동 권한 기능은 없었습니다. 정유리 강사의 누락 권한을 보완하고, 스텝 등급 변경 및 신규 영상 등록을 주기적으로 연결하는 기능을 배포했습니다.

정유리
기존 그룹 3개 보존. 영상 권한 39개와 STAFF 그룹 추가.
정은영
기존 42개 그룹 보존. 새 영상 권한 1개 추가.
현재 상태
두 명 모두 영상 권한 그룹 42개와 STAFF 그룹, 총 43개 연결. 그룹 수와 영상 편수는 다릅니다.

운영 규칙

  • 아임웹 최신 쇼핑 등급 ‘스텝’이 기준입니다. ARCHIVE STAFF 그룹만으로는 전체 영상 권한을 새로 부여하지 않습니다.
  • Mac mini의 전용 LaunchAgent가 300초마다 점검합니다. 신규 영상은 정식 40D 그룹·페이지 접근·내 강의실 카탈로그 등록 후 다음 점검에서 연결됩니다.
  • 스텝 해제 시 이번 기능이 추가한 그룹만 회수합니다. 기존 권한과 유효 구매 권한은 보존하며, 과거 수동 부여 권한을 회수 대상으로 소급 편입하지 않습니다.
  • E팀의 최초 부여일부터 40일 계산은 그대로 유지합니다. 스텝인 동안 만료 회수를 유예하고, 해제 후에도 유효 구매를 보호합니다.
  • 공유 잠금, 전체 주문 대조, dry-run 확인, 최종 회원 재조회, 변경 의도 저장과 결과 불명 재쓰기 금지를 적용합니다.
  • 20% 할인 설정, 상품·가격, 기존 구매 이력, 관리자 권한, 영상 및 페이지 ACL은 변경하지 않았습니다.

미완료 및 제한

일반회원 계정으로 실제 내 강의실 목록과 영상 재생을 확인하는 검증은 별도 로그인 세션이 없어 수행하지 않았습니다. 관리자 화면이나 API 권한 연결을 일반회원 재생 성공으로 보고하지 않습니다.

  • Mac mini 정지·로그아웃·인증 실패 중에는 자동 연결이 지연될 수 있습니다. 연속 오류는 운영자 메일로 중복 없이 보고합니다.
  • 현재 안전 한도는 영상 그룹 48개, 회원 그룹 변경 요청 50개입니다. 초과하거나 주문·등급·원장이 불명확하면 권한을 회수하지 않고 운영자 확인 대상으로 둡니다.
  • CORE 새 노트는 320·390·768·1440px 로컬 렌더에서 겹침과 내부 overflow가 없었습니다. 기존 다른 노트의 긴 식별자로 생기는 모바일 페이지 폭 405px 문제는 이번 변경과 무관하며 수정 범위에서 제외했습니다.
  • 회원 계정 로그인·비밀번호 변경·다른 회원 변경·실제 스텝 해제 실험은 하지 않았습니다. 회수는 모의 데이터로 검증했습니다.

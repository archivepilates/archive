ARCHIVE PILATES / 2026.09.05

ARCHIVE CORE 업무 화면 개선

오늘 처리할 대상은 먼저, 상세 정보와 완료 이력은 필요할 때 확인하도록 정리했습니다.

로컬 구현 완료 · 운영 배포 전
운영 데이터 변경, 실제 발송, 예약 수정, 배포와 GitHub push는 수행하지 않았습니다.

01

집계와 상태 구분

조회 실패와 실제 0건을 구분합니다. 알림톡 최근 내역과 미해결 상태를 따로 조회하며, 조회 한도에 도달하면 최소 집계임을 표시합니다. 리포트 공개만으로 회원 전달 완료로 판단하지 않습니다.

02

회원 중심 재등록 관리

새로 읽은 회원 원본의 수강권을 기존 요약보다 우선합니다. 같은 전화번호는 한 줄로 표시하고, 수강권별 상담 기록은 유지합니다. 오늘 연락·예정·복귀 대기·처리 이력으로 나누며 처음 20명만 노출합니다.

03

간결한 홈과 탐색

빠른 실행을 수강료 안내·회원가입서·주차등록·강사레슨 4개로 정리했습니다. 외부 도구는 접어두고, 모바일 메뉴는 버튼으로 열며 데스크톱에서는 메뉴 이름을 표시합니다.

04

업무 흐름 연결

프라이빗 오늘과 최근 7일 미처리를 분리하고 기록 화면으로 연결합니다. 강사레슨은 좌석 집계와 같은 명단을 펼쳐 보여줍니다. 추천식단 설문과 검토 화면을 서로 연결했습니다.

05

불필요한 오해와 누적 정보 축소

평가 자료가 없는 강사를 0점이나 개선필요로 표시하지 않습니다. 과거 입차 미확인은 주차 이력으로 접고, 실제 미해결 실패는 남깁니다. 중복 설명도 축약했습니다.

유지한 경계

  • 알림톡 발송 대상·스텝 제외·중복 금지 및 승인 규칙 유지.
  • 강사레슨 수강권 발급과 수동 반배정·예약 정책 유지.
  • 회원 원본, 상담 문서, 예약, 주차 작업을 임의로 삭제하거나 재계산하지 않음.
  • 새 컬렉션·권한 변경 없음. 추가 명단은 화면 조회용으로만 사용.
  • CORE 운영규칙에 구현 내용과 배포 대기 상태 기록.

검증

핵심 단위 테스트 52개, Functions 전체 빌드, 데이터 원천 정책·Functions 경계·Hosting 회귀 방어 검사 통과.

기존 반응형 검사 85개 화면 조합 통과. 실제 변경 DOM의 버튼·탭·검색 기능 검사 76건 통과, 320·390·768·1440px 스크린샷 62장 확인. 태블릿·데스크톱 상단 상태 문구 눌림을 수정한 뒤 재검사에서 실패 0건을 확인했습니다.

브라우저 검사는 외부 통신을 차단한 합성 데이터 환경입니다. 실제 운영자 로그인, Firestore 권한, 운영 원본 집계나 외부 발송 성공을 증명하는 검사는 아닙니다.

재실행 명령과 증거 위치
  • npm run test:core-operator-workflow
  • npm run verify:core-operator-workflow
  • npm run verify:archive-core-responsive
  • npm run build:function-codebases
  • npm run validate:data-source-policy
  • npm run validate:function-boundaries
  • npm run validate:archive-core-hosting
  • artifacts/core-operator-workflow/report.json 및 스크린샷

운영 적용 전

승인 후 최신 main과 충돌 여부를 확인하고 CORE Hosting 및 영향 Functions만 배포해야 합니다. 배포 후에는 실제 운영자 권한으로 조회, 원본 대비 집계, 발송 완료 판정과 명단을 다시 검증해야 합니다.

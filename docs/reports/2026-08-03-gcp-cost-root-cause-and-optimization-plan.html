기능을 유지한 절감 설계

  • 프라이빗 수업 후 기록 전에는 리포트 생성 대상을 매번 다시 읽지 않고 waiting_post로 둡니다.
  • 연락처 동기화는 pending/retry 전체를 읽은 뒤 거르는 대신 target과 nextRunAt이 도래한 작업만 조회합니다.
  • 누락 설문 확인은 10분에서 60분, Notion 백필은 30분에서 하루 3회, 리포트 fallback은 10분에서 60분으로 조정합니다.
  • 직원 설문 알림 10분 주기는 유지해 현장 응답 속도는 바꾸지 않습니다.
  • StudioMate write queue, 정산 대시보드 동기화, 출석 알림은 사용 중이므로 제거하지 않습니다.

예상 효과와 관제

Cloud SQL 고정비 17,286원은 다음 완전한 청구월부터 대부분 사라집니다. Firestore·Cloud Run·Scheduler 절감분은 실제 트래픽에 따라 달라지므로 고정 금액으로 단정하지 않고 BigQuery 상세 청구 내보내기로 월별 확인합니다.

  • 목표: 현재 기능을 유지하면서 월 GCP 비용을 다시 무료 또는 낮은 수천 원대에 가깝게 관리
  • 경보: 월 누적 비용과 전월 같은 날짜 대비 급증을 프로젝트·서비스·SKU 단위로 확인
  • 원칙: 기능 중단이 필요한 절감은 자동 실행하지 않고 운영자 판단 대상으로 분리

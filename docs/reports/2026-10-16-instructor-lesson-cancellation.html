강사레슨 수강 취소

운영 배포·라이브 검증 완료

사용 흐름

  1. 강사레슨 → 일정별 명단 → 회원의 수강 취소 선택
  2. 회원·날짜·취소 사유를 확인하고 수강 취소 요청
  3. 기존 맥미니 실행기가 StudioMate 원본을 재확인한 뒤 해당일 수강권을 사용불가 처리하고 연결 예약 취소
  4. 수강권·예약 결과를 각각 재확인한 뒤 취소 완료 및 잔여 좌석 반영

결제 환불, 아임웹 주문 환불, 이미 발송된 가입서·알림톡 삭제는 실행하지 않습니다. 수강권도 삭제하지 않고 사용불가 이력을 보존합니다.

오작동 방지

  • 운영자 권한·현재 명단·원본 회원 ID와 전화번호를 검증합니다.
  • 단일 일자의 미사용·비공유 강사레슨 (2T) 수강권만 자동 처리합니다. 중복·사용 이력·원본 불완전·진행 중 발송은 보류합니다.
  • 요청 키와 외부 실행 직전 기록을 보존하고, 응답이 끊겨도 사용불가 토글을 반복하지 않습니다.
  • 두 번의 처리 전 조회가 일치해야 실행하며, 처리 후에도 두 번 조회해 예약 취소·결제 무변경·다른 수강권 무변경을 확인합니다.
  • 취소 대기·확인필요 동안 좌석을 먼저 비우지 않습니다. 뒤늦은 동기화·주문·가입서·발송 결과가 취소 상태를 되돌리지 않도록 차단합니다.

승인된 실사용 취소 후속 확인

운영자가 별도로 승인한 1건은 원본 회원 ID 연결을 보완하고 기존 취소 API로 접수했습니다. 정기 실행기가 수강권 사용불가 처리를 1회 접수한 뒤, 사용불가 수강권이 활성 목록에서 사라져 후속조회가 보류됐습니다.

이전 수강권 보관함의 별도 카드와 렌더링 대기를 반영했습니다. 보관함 카드는 날짜를 표시하지 않으므로 단일 카드 선택 후 UI 원본 응답의 정확한 발급 ID·회원·센터를 다시 검증하며 중복 카드는 차단합니다. 추가 취소 없이 원본을 독립적으로 두 번 읽어 수강권 사용불가·예약 2건 취소·결제 무변경을 확인했습니다.

기존 작업의 원래 오류와 운영자 재검증 근거를 남기고 CORE 상태를 취소 완료로 정리했습니다. 실제 결제 환불은 하지 않았습니다. CORE API에서도 해당 회원이 일정 명단에서 제외된 것을 확인했고 다음 정기 실행은 실패 없이 종료됐습니다. 이 결과는 승인된 실사용 취소와 독립 검증의 완료이며, 수정된 자동 후속조회 전체 흐름은 다음 정상 운영 건에서 확인합니다.

후속 수정 3238f36d: 취소 집중 회귀 82건 통과. 맥미니 실행기가 검증한 수정본과 동일한 해시임을 확인하고 운영규칙 Hosting을 배포했습니다. Functions는 변경하지 않았습니다.

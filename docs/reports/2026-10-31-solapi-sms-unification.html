일반 문자 SOLAPI 통합

ARCHIVE PILATES OPS · 2026-10-31

승인된 범위

직접 작성하는 SMS·LMS·MMS는 SOLAPI를 사용합니다. 기존 세 경로인 강사회원 가입서 미작성 안내, 일반회원 서명 안내, 환불 예상금액 안내의 발송 부분을 교체합니다. 기존 영상 안내 LMS·알림톡은 SOLAPI를 유지합니다.

StudioMate·이폼싸인 자체 계약 초대 문자는 별도 보안·서명 기능이므로 유지합니다. 과거 미발송 건 수동 일괄 처리·시험 문자·작업 초기화·새 자동화는 승인 범위에 없으며 실행하지 않습니다.

유지하는 안전장치

  • 기존 원본·가입서·회원·수강권·취소·환불 검증과 정본 업무 키·승인·공용 잠금을 유지합니다.
  • 기존 StudioMate 접수·불명확 시도는 그대로 보존해 SOLAPI로 바뀌어도 재발송하지 않습니다. 제공자 이력은 SMS/LMS/MMS를 함께 대조합니다.
  • 일반 문자 09:00~22:59, 서명 미작성 안내 09:00~19:59를 실제 POST 직전까지 확인합니다. 원본 확인 후 단일 선점과 1회 요청만 허용하며 POST는 재시도하지 않습니다.
  • 접수 ID와 그룹 ID·실제 전송 문구/수신자 해시를 원래 작업에 저장하고 최종 전달은 별도입니다. 결과 불명은 보류하며 다른 발송 경로로 우회하지 않습니다.

연결 검증

현재 SOLAPI 등록번호 두 개 중 기존 승인 문자와 일치한 번호(끝자리 4425)를 전용 비공개 설정에 고정했습니다. 비밀 키는 기존 Secret Manager에서 읽으며 저장·출력하지 않습니다. LaunchAgent의 제한된 PATH에서도 설정과 인증값 로드 후 의도적인 무발송 중단을 확인했습니다.

현재 미작성 작업의 제공자 읽기 전용 사전 점검은 2026-10-31 10:36 KST에 원본 재검증 직전 중단 지점까지 도달했습니다. 제공자 GET 2회, POST 0회, 정본 쓰기 0회, 실제 문자 0건입니다. 이는 실제 접수·전달 증거가 아닙니다.

검증·배포 상태

구현·검증 완료. 운영 반영·CORE 규칙 배포·CI 결과는 아래 최종 증거에 추가합니다.

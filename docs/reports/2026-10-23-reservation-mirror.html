자료의 범위

  • StudioMate 전체 원본이 아니라 기존 수집 DB와 보관 파일의 보유 범위입니다. 이번 복사 과정에서 과거 누락 자료를 새로 확보한 것은 아닙니다.
  • 현재 수강권 관측과 2026.05.27 과거 발급 이력은 별도로 표시합니다. 두 시점의 잔여 횟수를 현재 잔여로 합산하지 않습니다.
  • 상품 28건은 발급권에서 도출한 참조이며 전체 상품 마스터가 아닙니다. 상품 기본 횟수는 추정하지 않습니다.
  • 홀딩 전체 기간·고유 ID, 결제·계약서·건강 정보·회원 메모 내용은 복사하지 않았습니다. 홀딩 오류 0건은 전체 홀딩 이전 완료의 증거가 아닙니다.
  • 초기 캡처만 완료했습니다. 주기적 증분 수집·삭제 반영·지연 감시 자동화는 아직 활성화하지 않았습니다. 실시간 미러로 안내하지 않습니다.

운영 격리

  • 기존 운영 DB는 읽기만 했고, 회원·수강권·예약·메모 변경이나 회원 발송은 없습니다.
  • 기존 자동화 실행 주기와 설정, 루트 Firebase 설정, CORE 파일은 변경하지 않았습니다.
  • 별도 DB의 브라우저 직접 접근은 모두 차단했습니다. 기존 운영 Firestore 규칙 릴리스 시각은 2026.10.21 09:31:16 UTC로 유지됐습니다.
  • 서버는 Firebase 인증 후 기존 CORE 권한 조회를 매번 확인합니다. 운영자만 허용하며 강사·비활성·비밀번호 변경 필요·권한 조회 실패는 차단합니다.
  • 변경 API는 없고 GET 이외 요청은 405입니다. 회원 데이터·인증값·원본 자료는 정적 배포물과 Git에 포함하지 않습니다.
  • 공개 서버의 전용 계정은 미러 DB 읽기만 허용해야 합니다. 운영 DB 접근 거부를 실제 실행 계정으로 증명하기 전에는 실데이터 앱을 공개하지 않습니다.

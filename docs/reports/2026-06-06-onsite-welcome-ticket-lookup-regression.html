ARCHIVE PILATES · 운영 오류 기록

현장 웰컴 가입서 수강권 조회 오류

2026-06-06 현장 웰컴 즉시발송에서 StudioMate 회원 상세 화면은 열렸지만 수강권 정보를 찾지 못해 가입서 준비가 실패한 건에 대한 원인과 재발방지 조치입니다.

결론

원인 확인

  • 정연수 회원은 StudioMate에서 정상 조회됐고, 실제 수강권도 있었습니다.
  • 실패 원인은 회원 부재가 아니라 StudioMate 상세 화면의 사용중인 수강권 영역이 늦게 로딩되는 타이밍 문제였습니다.
  • 이전 수정이 코어 작업트리와 실제 LaunchAgent 실행 작업트리 사이에서 어긋나 같은 오류처럼 재발했습니다.

확인된 데이터

  • 회원: 정연수 · 전화번호 끝자리 6648 · StudioMate memberId 4728226
  • 수강권: 프라이빗 10회 (원장/부원장)
  • 기간: 2026. 6. 5 ~ 2026. 7. 24
  • 결제금액: 770,000원

반복된 이유

  • ARCHIVE CORE 전환 작업트리의 코드가 개선되어도 실제 백그라운드 실행은 archivein-live-setup의 워커 파일을 사용하고 있었습니다.
  • 기존 대기 조건은 상세 화면에서 이름과 전화번호가 보이면 성공으로 판단했습니다.
  • StudioMate가 수강권 패널을 늦게 붙이는 경우, 이름과 전화번호만 읽고 즉시 검증에 들어가 수강권 없음으로 실패했습니다.

수정 내용

  • 실제 LaunchAgent 경로와 코어 작업트리의 process-onsite-welcome-requests.mjs를 같은 로직으로 맞췄습니다.
  • 상세 화면에서 이름/전화번호뿐 아니라 수강권명, 시작일, 종료일이 모두 읽힐 때까지 최대 20초 대기하도록 변경했습니다.
  • 실패/취소 요청에서는 진행 단계가 보이지 않도록 하여 알림톡 발송완료처럼 오해되는 표시를 줄였습니다.
  • 검증 스크립트가 실제 Mac mini LaunchAgent 실행 파일까지 확인하도록 보강했습니다.
  • 현장 웰컴 알림톡 발송 함수에 Solapi Secret이 주입되도록 publicSolapiRequestOptions를 분리 적용했습니다.
  • 실제 운영 도메인 in.archivepilates.com이 연결된 archive-pilates-in Hosting site도 배포 대상에 포함하도록 검증했습니다.

추가 확인: 알림톡 발송 실패

  • 실패 메시지: child "apiKey" fails because ["apiKey" is not allowed to be empty]
  • 원인: onsiteWelcomeRequest가 공개 요청 옵션만 사용해 Solapi Secret을 받지 못했습니다.
  • 조치: 현장 웰컴 발송 함수에만 SOLAPI_API_KEY, SOLAPI_API_SECRET, SOLAPI_PFID를 붙였습니다.
  • 재발방지: 릴리즈 가드에서 onsiteWelcomeRequest가 Solapi Secret 포함 옵션을 쓰는지 확인합니다.

검증

  • node --check scripts/process-onsite-welcome-requests.mjs 통과
  • npm run validate:onsite-welcome 통과
  • npm run build 통과
  • StudioMate 읽기 전용 테스트에서 정연수 회원의 수강권명, 기간, 결제금액 추출 확인
  • Firestore 최신 실패 요청에서 템플릿/후보 생성은 정상이고 Solapi Secret 주입 누락만 실패 원인임을 확인
  • in.archivepilates.com/onsiteWelcome/에서 최신 UI와 no-cache 헤더 반영 확인

남은 운영 판단

배포 필요 항목 있음

  • 가입서 준비 워커는 Mac mini LaunchAgent 파일 수정으로 다음 새 요청부터 반영됩니다.
  • 화면 단계 표시와 함수 응답 문구 보정은 Firebase Hosting 및 Functions 배포가 필요합니다.
  • 회원이 가입서 작성 완료 후 StudioMate에 자동 기입되는 단계는 아직 별도 구현이 필요합니다. 현재는 Firestore 계약서 제출 상태까지 저장됩니다.

ARCHIVE PILATES · WORKFLOW REVIEW

판매영상 제작 흐름 정규화

이번 작업이 오래 걸린 이유를 분리하고, 다음 판매영상부터 한 번의 입력으로 상품 자료·내 강의실·영상구매 목록·검증 대상을 함께 만드는 구조로 바꿨습니다.

기준일 2026.09.04카탈로그 29편현재 릴리스 ACA6 · ACH9로컬 구현 · 미배포

왜 오래 걸렸나

01 · 반복 입력

영상 하나가 여러 파일에 흩어졌습니다

상품 코드, 제목, 상품번호, 그룹, 시청 경로와 추천 관계를 내 강의실·판매 화면·검증 스크립트에 각각 다시 적어야 했습니다.

02 · 위젯 차이

새 페이지가 기존 판별 규칙과 달랐습니다

이번 숨김 페이지는 아임웹 기본 영상 위젯이었고 기존 로직은 커스텀 임베드만 찾았습니다. 관리자 확인으로는 드러나지 않아 일반회원 테스트에서 수정이 필요했습니다.

03 · 두 시스템 배포

공식 홈페이지와 아임웹 순서가 얽혔습니다

공식 홈페이지 자산을 먼저 올리고 아임웹 로더를 갱신해야 합니다. 중간 상태를 완성 상태처럼 검사하면 일시적인 실패가 발생합니다.

04 · 작업 범위

원본 2편과 미리보기 2편을 함께 처리했습니다

유튜브 업로드·처리 대기 뒤 상품·그룹·페이지·미리보기와 비로그인, 구매자, 비구매자의 모바일·PC까지 확인했습니다. 검증은 필요하지만 매번 대상을 수기로 만드는 일은 불필요했습니다.

새 표준 흐름

영상 입력

코드, 제목, 강사, 길이, 미리보기, 원본, 썸네일, 그룹

자료·상품 생성

상세 HTML과 숨김 페이지 설정을 만들고 중복 확인 후 상품 등록

카탈로그 반영

내 강의실·판매 목록·버전·검증 대상을 자동 동기화

회원 검증

상품 API, 공개 미리보기, 권한 차단, 일반회원 모바일·PC 확인

수동으로 남는 한 단계: 아임웹 공개 API가 회원그룹 생성과 숨김 페이지 영상 위젯 편집을 지원하지 않아 이 부분만 관리자 디자인 모드에서 처리합니다.

자동 보호 장치

검사방지하는 오류현재 결과
코드·상품번호·그룹·경로 중복다른 영상 권한 또는 상품으로 잘못 연결통과
장비 접두어와 카테고리캐딜락·체어·리포머·바렐 분류 오류통과
전체 영상 ID 공개 파일 유출상품 상세나 전역 스크립트에서 원본 링크 노출통과
아임웹 기본 영상 위젯 인식권한이 있어도 내 강의실 카드가 사라지는 재발통과
현재 릴리스 자동 선택검증 스크립트가 지난 영상만 검사통과

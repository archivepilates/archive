판단

연결된 CORE MCP의 목록과 원장 1건 조회는 각각 약 0.84초와 0.76초에 응답했습니다. 이번 측정에서 연결 장애는 관찰되지 않았습니다. 방화벽·Tailscale·앱 전체 장애나 모델 지연의 원인은 확정하지 않았습니다.

전체 목록 반복 로딩과 같은 자료의 브라우저·DB 재조회는 줄일 수 있습니다. 긴 대화와 반복 heartbeat도 문맥량을 늘리지만 각각의 지연 기여도는 측정하지 않았습니다. CORE 저장자료 처리와 StudioMate 계약·수강권의 실제 외부 작업은 구분해야 합니다.

개선 및 실측

업무 요약을 기본값으로 하고 정확한 operation/area의 상세만 선택 조회합니다. 전체 메타데이터는 view=detail로 유지합니다. 수정 준비에는 업무별 주의사항을 추가했습니다.

남은 단계

운영 반영·커밋·푸시 승인과 기존 MCP 재연결이 남았습니다. 현재 채팅의 연결이 새 코드로 바뀌었다고 주장하지 않습니다. CORE 운영규칙 문구도 소스에 배포 대기로 작성했으며 Hosting에는 아직 게시하지 않았습니다. 채팅 이력·자동화·권한·운영 설정은 변경하지 않았습니다.

현재부터 이미 확인한 지원 업무는 필요한 ID·필터로 직접 조회하고, 결과를 요약해서 사용합니다. 이 방식은 대화 삭제나 강제 문맥 초기화를 의미하지 않습니다.

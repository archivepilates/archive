StudioMate 회원등록 개편 대응

수정·무발송 검증 완료 / 운영 반영·커밋·배포·푸시 승인 확인, 배포 준비 중.
실제 새 등록 화면은 아직 공개되지 않았으므로 개편 후 E2E 검증 완료로 판정하지 않습니다.

확인한 원본

StudioMate 공지 225는 11/2 08:51 게시됐으며 11/17 14:00~16:00 KST 개편을 예고합니다. 시간은 변경될 수 있습니다. PC·관리자 앱에서 기본 회원정보 저장과 이용권 발급을 분리합니다. PC는 회원 저장 후 선택 안내 팝업이 나타나며 확인을 선택하면 수강권 발급으로 이어집니다.

11/2 10:13 KST 인증된 센터 세션으로 공지 이미지와 현재 빈 등록 화면을 읽었습니다. 이름·전화번호·등급·회원 저장 버튼은 각각 1개였고 이름·전화번호는 빈 값이었습니다. 입력·저장 없이 확인했고 로그인 후 비조회 HTTP 요청은 차단했습니다.

수정 내용

항목대응
회원 저장 확인기존 상세화면 이동뿐 아니라 공지 기반의 엄격한 저장 완료 안내 팝업도 구분합니다. 팝업의 확인·취소를 클릭하지 않고 전체 연락처·이름·원본 회원 ID를 별도로 대조합니다. 상세화면 ID가 있으면 검색 ID와 반드시 같아야 합니다.
회원과 수강권 분리회원 단계가 검증·기록된 뒤 기존 별도 수강권 발급 단계를 실행합니다. 회원 저장을 수강권 발급 완료로 간주하지 않습니다. 저장 결과 불명확·알 수 없는 팝업·신원 불일치는 자동 재시도하지 않습니다.
공지된 점검시간11/17 14:00 이상 16:00 미만 신규 회원·수강권 외부 제출을 보류합니다. 선점 전과 최종 제출 직전 모두 확인하며 기존 처리기를 사용합니다. 16:00 도달 자체가 서비스 정상화 증거는 아닙니다. 연장·로그인·화면 불일치는 확인필요로 남깁니다.
계약·웰컴회원정보만 있는 행은 발송 대상이 아닙니다. 기존 기준선이 있는 경우 며칠 뒤 수강권이 발급돼도 별도 신규 발급으로 감지됩니다. 첫 기준선의 과거분 무발송, 정규 상품·신원·서명·취소·환불·중복·시간 제한은 그대로 유지합니다.
적용 대상일반 강사레슨 등록 실행기, 범위가 제한된 기존 팀레슨 UI 어댑터, 공통 등록 화면 판별기. 기존 회원 수정 화면과 생년월일·주소 반영, 전역 계약 설정, 기존 계약/발송 원장은 변경하지 않습니다.

릴리스 보호·빌드강사 등록 릴리스·폐기한 현장 웰컴 보호 검사, 5개 Functions 코드베이스 로컬 빌드, 경계 검증(105개 export), 구문·diff 공백 검사 통과. 초기 경계 검사는 새 작업영역의 빌드 산출물 부재로 중단됐으나 로컬 빌드 후 통과했습니다.
독립 검토제한된 읽기 전용 에이전트 검토에서 구체적 결함 없음. 향후 실제 DOM·문구·검색 반영 타이밍은 미확인으로 명시.
추가 CORE 검사화면·재등록·강사 신원 검사 48건 통과. 선택 실행한 전체 CORE 검사 명령은 기존 알림톡 카탈로그 지문 불일치로 중단됐으며 수정 전 런타임에서도 동일하게 재현됐습니다. 이번 등록 대응과 무관한 카탈로그를 재생성하거나 배포하지 않았고 해당 전체 검사를 통과로 표시하지 않습니다.

남은 단계

  1. 승인된 소스를 origin/main에 정식 반영하고 맥미니 실행기와 CORE 운영규칙만 필요한 범위로 배포·검증합니다. CI/패키지 메타데이터 수정은 영향 탐지에서 보수적으로 전체 Functions로 표시되지만 실제 Functions 구현 변경은 없습니다. 불필요한 전체 Functions 배포는 하지 않습니다. 최종 Hosting 버전·CI·런타임 결과는 실제 완료 후 기록합니다.
  2. 11/17 실제 개편 후 등록 폼·안내 팝업·회원 Excel 열을 읽기 재검증합니다. 새 필드나 버튼을 추측해 자동 제출하지 않습니다. 실제 생성·발급 테스트는 별도 승인 대상입니다.

회원·수강권·계약·예약·메모 생성/수정, 알림톡·문자·서명요청, 큐 수동 실행, 기준선 초기화, 자동화 추가·주기·권한 변경은 없었습니다. 작업 브라우저와 공유 잠금은 정리했습니다.

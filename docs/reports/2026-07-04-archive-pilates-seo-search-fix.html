검색 노출 조정 결과

2026-07-04 11:52 KST 기준, 아임웹 SEO 설정에서 검색 차단을 해제하고 Google Search Console 소유권 인증과 사이트맵 제출까지 완료했다.

핵심 원인

아임웹 기본 도메인이 검색되지 않도록 설정되어 서버 HTML에 noindex, nofollow가 내려오고 있었다.

현재 상태

색인 허용 상태. 공개 HTML에서 noindex가 사라졌고, 설명/키워드/Google 인증 태그가 확인된다.

적용한 변경

  • 아임웹 SEO 권한 설정에서 기본 도메인 archivepilates.imweb.me 검색 허용으로 변경.
  • 메타 설명 추가: 부산 명지 5:1 오프라인 강사레슨, 온라인 클래스, 움직임 관찰, 티칭 언어, 수업 기록 중심.
  • 메타 키워드 보강: 아카이브필라테스, 강사레슨, 부산/명지 필라테스, 강사교육 등.
  • Google Search Console URL 접두어 속성 https://archivepilates.imweb.me/ 생성 및 HTML 태그 인증 완료.
  • 아임웹 Header Code 상단에 Google 인증 메타태그와 canonical 보정 스크립트 추가.
  • Google Search Console에 sitemap.xml 제출.

남은 작업

  • 네이버 서치어드바이저: 네이버 로그인 세션이 없어 등록이 중단됐다. 네이버 로그인 후 사이트 등록, HTML 태그 인증, 사이트맵 제출이 필요하다.
  • Google 사이트맵 상태: 제출 직후 테이블에는 가져올 수 없음으로 보일 수 있다. 실제 사이트맵은 200 XML이므로 24-48시간 후 Search Console에서 재확인한다.
  • 도메인 표시: 현재 archivepilates.com은 포워딩 구조라 검색 결과는 최종 도착 주소인 archivepilates.imweb.me로 노출될 가능성이 높다. 검색 결과에 archivepilates.com을 계속 남기려면 향후 아임웹 개인도메인/SSL 직접 연결이 필요하다.

참고

  • Google 공식 문서: 사이트맵 제출은 Search Console 또는 robots.txt의 Sitemap 라인으로 알릴 수 있으며, 제출은 색인 보장을 의미하지 않는다.
  • 네이버 공식 문서: 웹마스터도구에 RSS/사이트맵을 제출하면 네이버 검색로봇이 주요 URL을 재방문하는 창구로 활용한다.

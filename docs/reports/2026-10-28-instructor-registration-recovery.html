강사레슨 발급 검증·가입서 복구

수정·무발송 검증 완료. 운영 반영과 승인된 두 건의 실제 복구를 진행합니다. 추가 수강권 발급과 기존 확정 알림톡 재발송은 하지 않습니다.

확인한 상태

발급 검증 중단 1건은 원본에 해당 수강일 수강권이 정확히 1개 있고 결제액도 일치했습니다. 발급 응답 뒤 검증 오류로 고유번호 연결이 끝나지 않은 상태입니다. 별도 가입서 실패 1건은 수강권 발급과 확정 안내 발송 기록이 있고, 현재 공동 주문 검증은 통과하지만 과거 실패 상태가 남아 있습니다. 두 건은 서로 다른 단계이며 회원별 상세 정보는 접근 제한 원장에 보존합니다.

재발방지

  • 발급 응답 고유번호를 화면 검증 전에 보존하고, 원본 접수 흔적이 있으면 새 발급을 차단합니다.
  • 숨김·중첩 카드를 제외하고 화면 중복은 한 번만 읽기 재확인합니다. 실제 중복·응답 불명은 자동 복구하지 않습니다.
  • 다인 주문의 불변 원본 검증과 회원별 운영 대기를 구분합니다. 처리 대기는 실패 횟수나 결제 승인 해제로 전파하지 않습니다. 원본 변경·취소·환불은 계속 공동 차단합니다.
  • 가입서 미발송 복구는 같은 작업 ID와 기존 시도 이력을 유지하며, 원본 문서함 부재와 접수·결과 불명 흔적이 없음을 확인한 건에 추가 1회만 허용합니다.
  • 기존 확정 알림톡·원장·중복방지·야간 금지·일반 전자계약 보류와 정기 주기를 유지합니다.

검증과 배포

합성 데이터만 사용한 강사레슨·주문·발송시간 회귀 테스트 976건을 통과했습니다. Hosting/catalog와 공백 검증도 통과했습니다. 변경은 Mac mini 실행기와 CORE 운영규칙이며 Functions 소비 영역은 없습니다. 검증용 조회 외 실제 회원 전송은 아직 실행하지 않았습니다. 운영 배포·독립 확인과 실제 복구 결과는 후속 결과에 기록합니다.

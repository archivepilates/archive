원인

  • 같은 회원목록과 예약 엑셀을 내려받아도 매시간 약 1,700개 문서를 다시 쓰고 있었습니다.
  • 시간별 동기화가 월 전체 프라이빗 회차 보정을 호출해 장시간 Function 실행과 504 응답을 만들었습니다.
  • 설문 미제출 점검이 이미 경고 메일을 보낸 후보까지 10분마다 다시 조회했습니다.

적용 내용

  • 회원·연락처·수업·예약에 안정적인 import hash를 적용하고 내용이 같은 문서는 쓰지 않습니다.
  • 예약 변경 시 해당 프라이빗 회원만 privateSessionLedger를 다시 계산합니다.
  • 강사 화면 재생성 기준에서 최신 파일명 의존을 제거해 변경 문서 생략 시에도 화면 누락이 없게 했습니다.
  • 설문 점검은 최근 60일의 프라이빗 설문만 보고, 기존 경고 문서를 먼저 확인해 추가 조회를 차단합니다.
  • 전체 월간 보정은 매일 23:30 안전 점검으로 유지합니다.

예상 효과

  • 변경이 없는 평상시 기준 Firestore 반복 쓰기 약 3.5만~4.1만 건/일을 줄입니다.
  • 시간별 전체 월간 보정에서 발생하던 장시간 Cloud Run/Functions 실행을 제거합니다.
  • 설문 후보·응답·예약의 반복 조회를 줄이고, 실제 변경과 미제출 건만 처리합니다.

검증

  • 공개 화면 미리보기: 홈 / index / 영상 목록 / AB10 / 니티도 / 강사레슨, 320·390·768·1440px 총 24조합 통과.
  • 새 회귀 테스트: 공통 화면 12개, 내 강의실 11개, 총 23개 통과. 기존 SEO·메뉴·배송상품·카탈로그·로더 검증 통과.
  • 실제 일반회원: 권한 있는 계정은 모바일·PC 각 10개 수업 표시, 비구매 계정은 각 0개. 관리자 수동 우회 없이 fetch 경로로 확인했고, 테스트 계정 그룹은 원래 0개로 복원했습니다.
  • 테스트한 수업: AR6·AB10과 8월·9월 A/B/C/D 수강생 공유 영상. 전체 과거 주문 및 실제 카드결제를 새로 실행한 검증은 아닙니다.
  • 비로그인: 내 강의실과 최신 판매·공유 시청 경로는 로그인 이동 302를 유지합니다.
  • 상품 1 API 전후 비교: productImages와 editTime만 변경. 가격·설명·판매 상태 등 나머지 상품 필드는 동일합니다.
  • 아임웹 Header Code 재열기 후 저장 문자열 동일, 리뉴얼 CSS·JS 각각 1회 연결 확인.
  • 공개 라이브 최초 24조합 중 18개 통과. 사진 및 요청 제한으로 남은 6개 조합은 수정 후 별도 순차 재검증하여 핵심 화면 검증 모두 통과했습니다. 마지막 6조합 모두 CSS v=20260927c를 확인했습니다. 단일 최종 버전으로 전체 24조합을 다시 실행한 결과는 아닙니다.
  • PC 카운트다운과 상품 열은 좌측 95px, 우측 1345px, 중심 720px로 일치합니다. 니티도 단체사진은 320·768·1440px에서 표시 및 비율을 확인했습니다.
  • 검증 중 Imweb HTTP 429가 발생해 요청을 중단했습니다. 이후 HTTP 200 복구, 최신 배포 후 내 강의실 보호 검증 통과, 마지막 6조합에서 429 재발 없음까지 확인했습니다.
  • 최종 메뉴 확인에서 사이드바의 기존 영문 전환 효과가 발견되어 CSS 적용 범위를 보완했습니다. 최종 d 버전에서 실제 메뉴 1920·390px의 hover/focus 4개 검사 통과: 한글 유지, 영문 숨김, 글자 크기 유지, 위치 변화 0px, 키보드 포커스 표시, URL 이동 없음. 테스트 브라우저는 모두 닫았습니다.

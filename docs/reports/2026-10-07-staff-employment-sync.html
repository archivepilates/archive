강사 근무명단 연동

확인된 원인

기존 화면은 로그인·연락처 정책에도 쓰이는 active 값을 근무 상태로 해석했습니다. 과거 강사 스캔은 정기 동기화에 연결되지 않았고, 일부 강사만 확인한 기록이 남아 있었습니다.

기준인원확인 내용
StudioMate 전체 직원 명단5명김기효, 배민진, 이초림, 정유리, 정은영

반영 구조

  • StudioMate 필터 없는 전체 명단 → staffs 근무 상태 → CORE 표시.
  • 기존 Excel 동기화 작업에서 24시간 경과 후 직원 탭을 확인합니다. 새 주기 작업은 만들지 않습니다.
  • 누락·빈 명단·부분 조회·식별 충돌·급격한 명단 감소는 반영을 차단합니다.
  • 로그인 권한, 알림톡 제외, 연락처, 수업·급여·평가 이력은 변경하지 않습니다.
  • 브라우저 잠금 충돌은 기다리지 않고 운영 경고를 남기며 다음 정기 실행에서 재확인합니다.
  • 강사 조회 실패가 정상 완료된 회원·예약 원천의 최신성까지 무효화하지 않도록 분리했습니다.

검증

회귀 테스트 87개, CORE Hosting 검사, 기존 기능 롤백 방지 검사를 통과했습니다. 전체 명단 대조 후 근무 상태 12건을 반영했고 기존 13개 직원 문서의 근무 상태 외 모든 필드가 그대로임을 검증했습니다. 일일 중복 조회 방지도 확인했습니다. 신규 강사 동시 등록 시 기존 권한을 덮어쓰지 않으며, 점검 시스템이 강사 동기화 경고를 정상으로 지우지 않도록 보강했습니다. Functions 변경은 없습니다.

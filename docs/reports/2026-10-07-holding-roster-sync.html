기존 Excel로 정지명단 변경 감지

회원목록 Excel을 이미 읽는 단계에서 원본 행을 재사용하도록 개선했습니다. 별도 전체 다운로드나 전체 회원 상세 조회는 추가하지 않습니다. 현재는 로컬 구현이며 배포·운영 설정·실제 발송은 변경하지 않았습니다.

기존 데이터로 가능한 범위

기존 importer는 전화번호, 수강권명, 수강권상태, 수강권시작일·종료일, 수강권최종수정일을 읽습니다. 실제 보관된 2026.05.27 정규화 자료의 2,903행을 기존 열 형태로 대응해 새 파서를 검증했습니다. 정지 16행, 회원 13명을 누락 없이 인식했습니다. 이는 과거 자료의 검증 결과이며 오늘 정지회원 수가 아닙니다.

최근 정기 실행 보고서는 2026.10.07 18:39 기준 3,419행·984그룹 처리와 원본 삭제를 기록합니다. 해당 원본은 이미 정리되어 이번 작업에서 최신 Excel의 실제 정지회원 수를 재계산하지 않았습니다. 코드가 읽는 열과 과거 실제 자료를 확인한 것이며 최신 원본 전체성 검증과는 구분합니다.

바뀐 흐름

기존 정기 다운로드 → 회원 원본 행 파싱·기존 회원 가져오기 → 원본 정리 전에 정지명단 비교·상세 조회 작업 저장 → 해당 대상만 읽기 전용 상세 확인

상태처리
최초 명단무발송 기준선. 현재 정지된 수강권의 최초 기간·전체 이력 수집 준비
새로 포함신규 정지 가능성으로 상세 확인. 명단 변화만으로 즉시 발송하지 않음
계속 정지해당 정지 수강권만 다시 확인. Excel 표시가 같아도 상세 날짜 수정이 숨겨질 수 있어 조회 유지
명단에서 빠짐종료·취소·상태변경 여부 상세 확인. 정지 해제를 자동 확정하지 않음
동일 상품 복수·회원 ID 불명확확인필요로 보관. 행 순서나 상품명으로 발급권을 추측하지 않음

누락·오작동 방지

  • 정지된 수강권을 제외하는 activeTickets 대신 필터링 전 원본 행을 사용합니다. 새 정지회원이 기존 memberProfiles에 없어도 명단에는 남깁니다. 실제 상세 조회에는 정상 StudioMate 회원 ID가 필요하며 미확인은 검토 상태입니다.
  • 전화번호는 정규화 후 해시로 비교합니다. 기준선에는 회원 이름·전화번호·메모 원문을 복제하지 않습니다. 상품별 행 개수는 유지합니다.
  • 빈 파일·필수 열 누락·오래된 파일·역순 실행·조회 범위의 큰 감소는 기준선을 갱신하지 않습니다. 소규모 누락도 해제 확정이 아닌 상세 조회 대상으로만 남깁니다.
  • 정지명단은 발송 원천이 아니라 읽기 전용 조회 범위입니다. 상세 확인 결과와 별도 승인된 canonical 원천만 기존 후보·발송 큐에 연결할 수 있습니다.
  • 대상은 실행당 최대 10건, 보류된 작업은 다음 실행까지 유지합니다. 조회 후 더 최신 작업이 생겼으면 이전 작업 결과로 완료 처리하지 않습니다.
  • 관찰 작업은 기존 회원·예약 가져오기와 분리한 보조 단계입니다. 실패 시 경고를 남기되 다른 데이터 가져오기를 중단시키지 않습니다.

제약과 운영 전환

Excel만으로 최초 발급기간, 개별 정지의 시작·종료일, 수정·취소 이력까지 확정할 수는 없습니다. 해당 회원의 상세 조회는 여전히 필요합니다. 예정 정지가 Excel 명단에 표시되는지도 아직 확인되지 않았으므로 등록 즉시 안내를 보장하지 않습니다.

현재 다운로드 코드에는 필터 범위·예상 전체 회원 수를 검증한 증거가 없습니다. 필수 열 존재와 행 개수 감소 방어는 전체 회원 누락 없음의 증명이 아닙니다. 실제 최신 원본·화면 명단 비교가 운영 전환 조건입니다.

관찰 활성화는 STUDIOMATE_HOLDING_ROSTER_OBSERVER=shadow, 상세 조회는 STUDIOMATE_HOLDING_SOURCE_SCAN=enabled와 settings/holdingNotice.sourceScanEnabled=true, rosterDiscoveryEnabled=true가 필요합니다. 이번 작업에서는 변경하지 않았습니다. canonical 원천 쓰기는 기존의 별도 감사·승격·대상 허용 조건을 그대로 유지합니다.

이번 개선은 정지명단 비교와 상세 조회 범위 연결입니다. 정지 식별자 자동 매핑·후보 자동 승인·실제 자동발송 활성화까지 완료했다고 표시하지 않습니다.

검증 상태

정지명단 테스트 65개와 조회 작업 보호 테스트 3개를 포함해, 선택한 관련 테스트 총 1,235개가 통과했습니다(Node 358개, TypeScript 877개). 회원가입·웰컴·스텝 제외·중복방지·원천 정책·브라우저 잠금 회귀 검증을 포함합니다. 문법 검사와 데이터 원천 정책 검사도 통과했습니다.

독립 검토에서 발견한 동시 실행 문제를 보강했습니다. 상세 조회가 끝나기 전에 새 명단을 받으면 이전 조회는 최신 원천을 승격하거나 무효화할 수 없습니다. 작업 버전과 대기 상태를 원천 쓰기 트랜잭션 안에서 다시 확인합니다.

실제 브라우저 수집·운영 Firestore 쓰기·StudioMate 변경·SOLAPI 발송은 실행하지 않았습니다. 이번 작업에서 브라우저를 열지 않았습니다. 운영 배포와 활성화는 별도 단계로 남아 있습니다.

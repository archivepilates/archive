권한과 문자

  • StudioMate 실제 수업 4개 출석을 대조했습니다. 팀별 두 수업 모두 출석한 10명이며, 홈페이지 최신 전체 회원의 이름·전화번호 동시 일치 계정은 8명입니다.
  • 신규 그룹 저장·회원 정보와 기존 그룹 보존을 2명에게 독립 확인했습니다. 기존 STAFF 수강생 1명은 스텝 그룹을 제거·재추가하지 않고 별도 수강생 공유 사유와 최초 40일 시각을 기록했습니다.
  • 나머지 5명은 CLI 로컬 일일 수정 안전한도 99/100으로 전송 전에 차단됐습니다. 한도 변경·자동 우회는 하지 않았습니다. 별도 관리자 화면 처리 승인 또는 다음 KST 날짜 한도 초기화 뒤 원천 재대조가 필요합니다.
  • 미가입 1명은 기존 e-2 소비자에 문자 대기 1건을 연결했습니다. 실제 발송 시도 0회, 공급자 예약 없음입니다. 09:00~23:00에 현재 가입·출석·취소·중복을 다시 확인한 뒤 기존 점검에서 처리합니다.
  • 동명 계정 1명은 연락처가 비어 본인 확인 보류입니다. 해당 계정을 미가입으로 단정하거나 권한·문자를 부여하지 않았습니다.

이용기간은 각 회원의 최초 확인된 권한 부여 시각부터 960시간입니다. 재실행으로 초기화하지 않으며, 스텝 해제 시 유효한 구매와 남은 수강생 권한을 보존합니다. 기존 E팀 5명의 최초 시각도 유지합니다.

검증 범위

  • 4개 완성본 H.264/AAC, 3840×2160, 30fps, 해시 보존 확인. YouTube 채널·일부공개·처리 완료·임베드 허용을 독립 재조회했습니다.
  • 일반 테스트 계정에서 A/B 각 2편의 실제 플레이어 시간이 증가했습니다. 교차 팀, 권한 원복 후, 로그아웃 상태는 차단됐고 허용되지 않은 화면에 YouTube 플레이어가 없었습니다.
  • 320·390·768·1440px에서 새로 접속한 팀 페이지는 수평 넘침 없이 표시됐습니다. 테스트 계정의 임시 그룹은 원래 상태로 복구 후 API로 확인했습니다.
  • 4편 모두 한국어 교정 자막 serving과 일본어 제목·설명 저장을 독립 API 재조회로 확인했습니다. 모델 기반 용어·타임코드·낮은 신뢰도 구간 재전사 검토이며, 사람의 원음 전체 전수 검수는 하지 않았습니다. 기존 한국어 제목·설명·태그와 일부공개 상태를 보존했습니다.
  • 내 강의실 신규 카드의 일반회원 발견 검증은 미완료입니다. 기존 페이지 재생 검증을 신규 카드 검증으로 대체하지 않습니다.

배포 및 소스

소스 검토·테스트 후 내 강의실 공통 자산 1개와 CORE 운영규칙 1개를 기존 Hosting 3곳에 각각 단일 파일 교체 방식으로 반영합니다. 이 문서의 후속 배포 영수증에서 실제 적용 여부를 구분합니다.

Functions·상품·가격·구매 이력·회원 연락처·다른 페이지와 주기는 변경하지 않습니다. 운영 원장·출석·회원 연락처·OAuth 자료는 소유자 전용 로컬 저장소에 두며 Git에 포함하지 않습니다.

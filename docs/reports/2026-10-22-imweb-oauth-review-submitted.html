앱 심사 접수 완료

기존 앱을 재조회한 상태는 심사중입니다. 승인·게시·사이트 연동 완료나 실제 웹훅 운영 전환을 뜻하지 않습니다. 현재 사용자가 직접 누를 동의 단계는 없습니다.

이번에 완료한 것

  • 승인된 기존 앱 인증정보를 archive-pilates Secret Manager의 전용 Secret 버전1에 보관했습니다. 원문은 채팅·Git·로컬 파일에 저장하지 않았고 임시 암호화 전달 파일과 키는 제거했습니다. 기존 CLI 인증은 유지했습니다.
  • 실제 서비스 URL과 OAuth 콜백을 기존 앱에 저장하고 재조회했습니다. 요청 범위는 기존 사이트 정보 읽기·쓰기, 승인된 회원 정보 읽기·쓰기, 기존 주문 읽기뿐입니다.
  • 앱 심사 요청을 한 번 제출하고 새로고침 후 ‘심사중’을 확인했습니다. 포털 안내 기간은 영업일 기준7~10일이며 승인 결과는 미정입니다. 추가 기술문의 메일은 보내지 않았습니다.
  • 운영자 전용 시작 링크,20분 창, 보안 쿠키·일회 상태, 암호화 보관, 취소·만료 재검사, 결과 불명 시 자동 재시도 중단을 갖춘 imwebOAuthApi만 새로 배포했습니다.
  • CORE 기존 웹훅 운영규칙 한 항목을 보관 완료·심사중·승인 후 연결 순서로 갱신했습니다. 기존40일·스텝 해제 보호·회원·구매·할인·정기 점검은 변경하지 않았습니다.

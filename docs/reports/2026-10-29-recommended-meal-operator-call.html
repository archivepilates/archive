구현·로컬 검증 중. 배포 및 승인된 비공개 초안 저장은 아직 완료 판정 전입니다.

변경 내용

  • 설문 제출 시 작성 대기로 접수하며, Gemini/OpenAI 모델 API와 기본 식단 자동 생성은 중단합니다.
  • CORE의 작성 요청 복사는 요청 ID만 복사합니다. 이 채팅을 자동 실행하는 기능은 아닙니다. 관리자가 현재 채팅에서 작성·저장을 요청합니다.
  • 추천식단 화면은 진행 목록과 검토 영역을 분리하고 설문·초안·7일 일자별 편집·생활 가이드 순으로 정리했습니다.
  • 공개·발송은 별도 기존 승인 절차입니다. 이번 테스트에서는 실행하지 않습니다.

원본 및 저장 안전장치

실행 원천기존 추천식단 요청·응답·초안·리포트 4개 canonical 컬렉션
동시 편집응답 sourceHash와 초안 revision을 트랜잭션에서 재확인합니다. 변경되면 저장하지 않습니다.
보존회원 응답은 쓰지 않습니다. 교체된 초안은 동일 요청의 revisions 하위 이력에 보존합니다.
공개 잠금승인·공개·발송 상태, 스냅샷, 후보 연결이 있으면 초안 수정을 차단합니다.
개인정보건강·알레르기·InBody는 내부 안전 검토용입니다. 외부 모델 API 호출이나 설문 원문 클립보드 복사는 없습니다.

초안 품질 기준

승인된 테스트 회원의 기존 식사 환경에 맞춰 7일 구성을 직접 작성했습니다. 식사 시각은 근무에 따라 이동하고 간단식은 선택으로 두며, 구내식당 대체 메뉴·10분 내 준비·단 음료·야식·모임 대응을 구체화했습니다. 고정 열량이나 감량 속도를 처방하지 않았습니다.

일반 생활 안내 참고: CDC NIOSH 교대근무 식사 안내, Health Canada 균형 식사 구성. 개인별 의료·영양 처방을 대신하지 않습니다.

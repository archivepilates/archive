변경 내용

  • 내 시퀀스의 개별 ‘응답 저장’을 ‘PDF 저장’으로 교체했습니다. 선택한 서버 저장본과 사진을 읽어 바로 PDF로 내려받습니다.

  • 복원용 응답 파일 및 최근 기록 백업은 별도 JSON 기능으로 유지합니다.
  • CORE 운영규칙에 PDF 저장과 삭제 표식, 명시적 복원 기준을 기록했습니다.

삭제 현상 판정

읽기 전용 확인에서 삭제한 원본 ID는 삭제 상태였습니다. 같은 제목의 별도 복구본은 19:03에 만들어졌고 원본 삭제는 19:56이므로, 삭제 이후 자동 재생성된 기록이 아닙니다. 실제 운영자의 원본·복구본은 임의 삭제하지 않았습니다.

삭제한 ID는 삭제 표식으로 보존되어 오래된 다른 기기의 저장을 거부합니다. 재접속과 과거 localStorage로 자동 복원하지 않습니다. JSON 복원은 확인 후 새로운 ID의 사본으로만 생성됩니다.

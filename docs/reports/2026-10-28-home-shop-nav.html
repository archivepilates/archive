판매상품을 독립 메뉴로 이동

상단 순서는 팀아카이브 · 아카데미 · 판매상품 · 채용입니다. 아카데미에는 강사레슨과 영상구매 두 항목만 남깁니다.

변경 범위

  • 홈·강사레슨 안내·팀 소개·강사 소개5명, 총8개 공통 헤더에서 동일하게 이동.
  • 판매상품은 기존 /shop 경로를 유지하며 상품 목록·가격·재고·구매·쿠폰·회원 권한은 변경하지 않음.
  • 커뮤니티 상단 숨김과 본문 기록·게시글·강사 사진·교육 링크는 유지.
  • 8개 HTML의 두 줄 이동만 반영하며 CSS·JS와 기존 강의실 파일은 변경하지 않음.

배포와 보존

Git main의 최신 운영 변경을 보존한 별도 작업 브랜치에서 진행합니다. 홈페이지는 현재80개 파일 중8개 HTML 해시만 바꾸고 나머지72개 파일과 Hosting 설정을 보존합니다. 현재 CORE 운영규칙의 기존 메뉴 기록 한 건만 갱신하고, 내용이 다른 과거 미러 페이지는 변경하지 않습니다. 실제 배포 버전·커밋·CI 및 라이브 재조회 결과는 별도 배포 증거 파일과 채팅 완료 보고를 기준으로 확인합니다.

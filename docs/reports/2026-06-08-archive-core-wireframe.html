detail

  • 개선 방향: 요약/판단/이력을 탭 또는 접힘 구조로 분리

Lessons

수업 운영, 폐강/조정, 원천 상태

lessons
  • 오늘 수업, 강사별 이번주, 원천 상태, 폐강/조정
  • 개선 방향: 문제 있는 수업과 상세 drilldown 우선

Private

프라이빗 차트 4단계 진행

best pattern
  • 수업전, 수업후, 리포트 완성, 리포트 전송 단계
  • 개선 방향: 다른 메뉴에도 작업 상태 보드 패턴 확장

Messages

알림톡 후보, 템플릿, 발송/실패

guardrail
  • 오늘 판단, 템플릿 현황, 최근 후보, 발송/실패
  • 개선 방향: 템플릿별 중복 방지 기간과 실패 사유 표시

Automation

동기화, 다운로드, import 관제

health
  • 수집, 정규화, 핵심 건강도, 외부 실행 경계
  • 개선 방향: 실패/지연/다음 실행 예정 우선

Business

경영 지표와 월별 흐름

metrics
  • 월 총매출, 수업매출, 마진률, 그룹 출석률
  • 개선 방향: 비교 기준과 원본 품질 경고 명확화

Imports

원본과 데이터 품질

source
  • 원본 처리 기록, 열린 품질 이슈, stop rule
  • 개선 방향: 원본별 root cause와 최신성 표시

Rules / Settings

운영 규칙과 시스템 경계

static
  • Rules: 외부 액션 원천, workLanes, 중복 데이터, Notion
  • Settings: 도메인, 권한, 배포, write 보호

UPGRADE PRIORITIES

UI/UX 개선 우선순위

GPT와 논의할 때 바로 비교 기준으로 쓸 수 있는 개선 후보입니다.

next
1

Home 재정의

전체 요약보다 오늘의 문제, 확인 필요, 운영 우선순위 중심으로 바꾼다.

2

Private 패턴 확장

4단계 진행 보드 구조를 Messages, Automation, Imports에도 적용한다.

3

Members 병합 표시

중복 회원은 목록에서 하나로 보이고 상세에서 alias와 원천을 펼친다.

4

Lessons 예외 우선

정상 수업보다 폐강, 조정, 출결 이상, 예약 이상을 먼저 보여준다.

5

Business 신뢰도

숫자마다 비교 기준, 원본 상태, 품질 경고를 같이 보여준다.

6

Imports 원인 분석

단순 로그가 아니라 원본별 품질 이슈 root cause 보드로 바꾼다.

DESIGN NOTES

디자인 개선 메모

현재의 장점은 유지하고, 반복되는 카드와 설명 중심 구조는 줄입니다.

visual guide
유지할 점

운영자 전용의 차분한 밀도, 주황 accent, 상태 pill, canonical 경계 표시.

줄일 점

모든 섹션이 같은 카드처럼 보이는 단조로움과 반복 설명 문구.

고칠 점

첫 카드 높이 불일치, 섹션 간격, 모바일 overflow, tooltip z-index 문제.

강화할 점

실패/주의/다음 액션을 더 앞에 배치하고 숫자의 원본 신뢰도를 표시.

2026-11-02 · 검증 및 배포 준비 기록

원인과 수정

기존 결제 완료 주문의 OPEN/배송완료 → CLOSED/구매확정 전환이 전체 원본 해시 변경으로 판단되어, 완료 접수 두 건에 공동 보류가 설정됐습니다. 원본 대조에서 다른 변경은 없었습니다.

순방향 상태 전환만 이전 상태로 복원해 기존 승인 해시와 대조합니다. 원본의 다른 모든 필드는 계속 해시에 포함하며 현재 결제·취소·환불·신원·수강일 검증을 유지합니다. 기존 승인키나 원본 감사기록을 새 해시로 덮어쓰지 않습니다.

복구 범위

승인된 기존 완료 접수 두 건만 대상으로 합니다. 최신 주문·StudioMate 수강권·기존 가입서 완료 원장·동일 SOLAPI 메시지 전달 이력 확인 후 transaction으로 잘못된 보류 표시만 복구합니다. 수강권 발급·가입서 요청·알림톡 재발송·새 작업 생성은 하지 않습니다.

검증과 배포

  • 구현: 정책·복구 도구·CORE 규칙 수정. 실제 배포와 상태복구는 별도 증거 확인 전 완료로 간주하지 않습니다.
  • 정상 전환·역행·환불·취소·원본 변경·불변 승인키 및 무발송 회귀검증을 수행합니다.
  • 배포 범위: 기존 Mac mini 실행기와 CORE 규칙. Functions·보안규칙·실행 주기는 변경하지 않습니다.
  • 정확한 배포 커밋은 CORE release.json, 복구 결과는 접근 제한 canonical 감사기록과 최종 검증 보고로 확인합니다.

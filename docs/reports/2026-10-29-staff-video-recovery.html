AR7 누락 복구와 완료 판정 보강

실제 확인

스텝 두 계정에서 AR7 그룹 누락을 재확인했다. 이전 결과 미확인 의도는 자동 재실행하지 않았다. 운영자가 승인한 정확한 회원·의도 해시·현재 메타데이터·변경 전 그룹을 대조해 기존 불확실성을 이력으로 보존한 후 추가 전용 계획을 실행했다. 이후 기존 실행기도 같은 잠금 아래 남은 누락을 반영했다. 현재 두 계정의 AR7 포함과 기존 baseline 보존은 회원 상세로 재조회했다.

2026-10-29 02:06:07 KST에 48개 영상과 STAFF, 총 49개 그룹의 명단 및 두 회원 상세 독립 재조회가 모두 성공했다. 두 계정 모두 추가 변경 없이 기존 권한 보존이 확인됐고, 전체 완료를 원장에 기록했다. 최종 실제 시각과 해시 기반 결과는 비공개 imweb-staff-video/state.json → lastRun.verification을 정본으로 삼는다. 개인 연락처·구매 내역은 이 보고서나 Git에 포함하지 않는다.

변경한 동작

  • 불확실한 과거 의도는 그대로 보존한다. 현재 미반영 상태를 과거 미전송 증거로 바꾸지 않는다. 무인 실행은 여전히 결과 미확인 건을 재전송하지 않는다.
  • 확인된 로컬 한도 차단은 blocked_before_dispatch로 구분하고 동일 날짜 CLI 반복을 막는다. 관리자 후속 대기를 완료로 기록하지 않는다.
  • 권한 동기화 후 회원 상세와 전체 그룹 명단을 재조회한다. 이 검증 전에는 전체 성공 시각이나 관제 복구를 갱신하지 않는다.
  • 그룹 명단 GET 조회에 간격을 두고, 원격 속도 제한은 GET에 한해 한 번 제한적으로 대기·재조회한다. 쓰기 재시도나 한도 초기화는 하지 않는다.
  • 업로드 처리·재생·보호 페이지·강의실 연결의 신선한 비공개 증거를 확인한 뒤 공통 완료 명령을 실행한다. 실패하면 접근 대기이며 회원 안내는 별도 승인 전까지 미발송이다.
  • 기존 구매 권한·별도 권한·최초 부여일부터 40일·스텝 해제 시 남은 수강생 권한 보호는 유지한다. 상품·가격·할인·관리자 권한·회원 메시지는 변경하지 않았다.

앱 전환 경계

이번 실시간 조회에서 웹훅은 shadow, 운영 토큰 봉투 없음, 연동완료 검증 false, 실제 shadow 이벤트 0건이다. 앱 심사 승인 여부와 실제 사이트 연동 상태는 별개다. 앱 승인만으로 운영 권한 처리기를 활성화하지 않았다. 공식 절차의 사이트 권한 동의·연동완료 API·정본 큐 승격을 완료한 뒤 신규 가입·등급 이벤트를 동일 처리기로 연결해야 한다.

아임웹 공식 앱 연동 안내는 접근 동의 뒤 연동완료 처리가 필수이며, 연동중에는 다른 API를 사용할 수 없다고 명시한다. 이번 작업은 기존 CLI 인증을 유지했다.

검증과 범위

기능·소유권·구매/수강생 보호·결과 불명·한도 분류·완료 검증·배포 가드 관련 회귀 검사 328개를 통과했다. CORE는 기존 스텝 규칙 한 항목만 바꾸며 다른 운영규칙과 Hosting 파일·설정을 보존한다. 실제 릴리스 버전과 Git 식별자는 배포 영수증 및 최종 작업 응답에서 확인한다. 기존 5분 실행기를 재사용하며 새 폴러·스케줄러·Functions 배포는 추가하지 않는다.

일반회원 내 강의실 실제 재생은 이번 검증 범위에 포함되지 않았으며 완료로 주장하지 않는다. 현재 영상 그룹은 48개로 기존 안전 상한에 도달했다. 추가 그룹이 이를 넘으면 완료로 넘기지 않고 별도 구조 검토가 필요하다. 장기적으로 STAFF 공통 접근 그룹을 보호 페이지 ACL에 적용하는 방식은 별도 범위로 검토한다.

검증 완료 · 배포 준비

대상: booking-test.archivepilates.com

변경 범위

  • 모바일 주간 보기를 기본으로 유지하고 날짜·수업 카드 겹침, 시간축과 요일 헤더 고정, 달력 내부 가로 스크롤을 보완합니다.
  • 월·주·일 보기 선택을 브라우저 세션 동안 보존하며 월말·연말 날짜는 한국 시간으로 계산합니다.
  • 선택 기간 수업을 제한된 순차 페이지 조회로 읽으며, 오류나 한도에 도달하면 일부 조회 상태를 표시합니다.

운영 격리

실제 배포 대상은 기존 Firebase 로그인과 운영자 권한 확인을 유지한 조회 전용 미러입니다. 로컬 LAB의 모의 인증·가상 데이터·변경 기능은 공개 배포하지 않습니다. Cloud Run 서버 코드·운영 DB·미러 데이터·StudioMate·자동화·회원 발송은 변경하지 않습니다. 판매 홈페이지와 DNS도 유지합니다. 미러 원본은 초기 부분 스냅샷이며 이번 UI 개선이 실시간 동기화나 전체 자료 이전을 의미하지 않습니다.

검증

자동 테스트 196건 통과, 빌드 성공, 프로덕션 의존성 취약점 0건. 320·390·768·1440px 모두 페이지 가로 넘침 0이며 7일 열을 확인했습니다. 합성 70건 자동 조회, 일요일 선택·고정 시간축·상세 읽기·월요일 헤더·보기 유지·메뉴 전환·로그아웃 후 자료와 건수 초기화를 확인했습니다. 생산 번들은 실제 Firebase Auth를 포함하며 테스트 인증 표식이 없습니다. CORE Hosting 검증도 통과했습니다.

물리적 iPhone Safari가 아닌 Chromium 뷰포트 검증입니다. 실제 운영자 로그인 후 화면은 현재 인증 세션이 없어 별도 확인이 필요합니다. 인증 우회는 하지 않습니다. 지연된 페이지 응답 중 계정 전환의 브라우저 통합 검증은 미실행이며, 취소·권한·세대 가드의 소스 검토와 단위 검증으로 확인했습니다.

배포 증거

배포 전. 파일 해시·Hosting 버전·커밋·GitHub 상태는 완료 후 기록합니다. 기존 Hosting 구성과 변경하지 않는 파일 전체를 보존하는 전용 파일 교체 도구를 20건 테스트했습니다.

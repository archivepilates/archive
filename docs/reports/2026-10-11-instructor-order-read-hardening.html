확인된 문제

16:34 오류 알림에는 실패 단계와 상태코드가 남지 않았습니다. 주문 조회 함수가 상세 오류 정보를 잃었고, 정상 종료코드로 반환된 실패 응답을 명시적으로 차단하지 않았으며, 동기화 작업이 진단 정보를 알림 기록에 전달하지 않았습니다.

인증 토큰 갱신 시각이 오류 시각과 일치했지만 과거 원문 응답이 없어 실제 외부 장애 원인은 확정할 수 없습니다. 정기 전체 조회는 이 수정 배포 전 이미 정상 복구된 상태입니다.

적용한 보강

  • 주문 목록·단건 읽기에서 확인된 네트워크·429·5xx 오류만 0.5초 후 1회 재확인합니다.
  • 인증·권한 오류, 서로 모순되는 오류 정보, 해석할 수 없는 응답과 원본 불일치는 즉시 중단합니다.
  • 정상 종료코드여도 실패 응답이면 차단합니다. 전체 주문 목록을 다 읽지 못하면 신규 접수를 시작하지 않습니다.
  • 목록 조회·발급 전 단건 재확인 단계, 상태코드, 조회 시도 수를 보고서·관제·메일에 전달합니다. 개인정보·토큰·원문 응답은 저장하지 않습니다.
  • 일시 조회 오류의 3회 연속 실패 알림, 전체 정상 실행 후 복구 알림 1회, 수동 단건 조회·실행 생략의 복구 제외 규칙을 유지합니다.

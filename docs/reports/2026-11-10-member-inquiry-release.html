적용한 기준

  • 같은 지점의 현재 재직·CORE 인증이 유효한 모든 스태프가 문의를 열람합니다. 기존 근무·로그인 검증을 유지하며 권한 플래그를 일괄 부여하지 않았습니다.
  • 미배정 건은 직원이 담당으로 접수합니다. 일반 직원은 본인 담당 건을 검토·기록하고 관리자는 배정·현재 처리안 승인·반려를 진행합니다.
  • 접수일 기준 90일 보관. 만료 시 조회를 차단하며 요청·감사·중복 방지 이력에 각각 TTL을 적용합니다. 삭제는 플랫폼의 비동기 TTL 작업입니다.
  • 고정예약 취소·변경 불가 기준을 안내하고 예외·미확정 전환 기준은 관리자 검토로 분류합니다.
  • 현재 기능은 접수·검토·승인·수동 결과 기록입니다. 실제 예약·수강권·결제·환불·연락처·메모 변경이나 회원 발송은 자동 실행하지 않습니다. 문의 callable은 CORE UI 전용이며 범용 MCP에는 제외 사유를 명시했습니다.

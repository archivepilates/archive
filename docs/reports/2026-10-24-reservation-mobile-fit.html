원인·수정

912px 최소 너비가 모바일에서 2~3개 요일만 보이게 했고, 외부 스크롤로 오전 위치를 맞추는 방식은 Safari 화면에서 새벽 영역이 노출될 수 있었습니다. 7일을 컨테이너 폭 안에 맞추고 FullCalendar 자체 스크롤·08:00 초기 위치로 변경했습니다. 새벽 수업 데이터는 제거하지 않았습니다. PC의 요일·상세 표시는 유지하며 축약 수업과 겹친 수업은 상세로 확인합니다.

검증

합성 70건, 320·390·768·1440px에서 리사이즈 렌더 완료 후 페이지와 캘린더 내부 가로 넘침 없이 헤더·본문 7일이 모두 들어옵니다. 모바일 자체 스크롤의 오전 8시 위치, 월·주·일 전환, 다른 메뉴에서 크기 변경 후 복귀, 합성 로그아웃·재로그인, 겹친 수업 팝오버·상세 열기를 확인했습니다. 자동 테스트 202건 통과, 빌드·CORE Hosting 검사 통과, 미러 프로덕션 의존성 취약점 0건과 독립 검토를 확인했습니다. 실제 기기 Safari와 실제 운영자 로그인 후 검증은 미실행입니다. Node 25.9.0에서 로컬 검사했으며 Functions는 배포하지 않습니다. CORE 검사에 필요한 기존 Functions 의존성 설치가 누락되어 최초 검사가 중단됐으나 설치 후 통과했습니다. 그 기존 의존성 감사의 50건 경고는 미러 번들과 별개이며 이번에 변경하지 않았습니다.

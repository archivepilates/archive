친구 초대 기능 검증 결과

실제 가입·지급·중복 차단·회수 통과 / 공유 화면 연결·운영 배포는 미완료

초대자에게 가입 1건당 3,000원, 한국시간 한 달 최대 30,000원. 구매와 휴대폰 인증은 요구하지 않습니다.

완료한 범위

아임웹 기능 벤치마크
PC 우측 패널, 모바일 하단 패널, 링크 복사·공유 흐름을 확인했습니다. 무료체험은 9월 28일까지이고 자동갱신은 해지했습니다. 캠페인은 실행하지 않았습니다.
공유 화면과 링크
초대자만 받는 혜택 안내, 링크 복사·휴대폰 공유, 참여 안내를 구성했습니다. URL과 탭 저장소에는 공개 추천인 코드만 포함하며 회원 이메일·연락처·로그인 정보를 넣지 않습니다.
지급 보호 로직
아임웹 실제 가입 기록 기준으로 판단합니다. SQLite 원장에 신규 가입과 월 한도를 함께 예약하고, 지급 시도는 한 번만 허용합니다. 결과가 불명확한 지급은 보류하여 재지급하지 않습니다.

자체 화면 테스트 파일 열기

테스트 화면의 코드는 가상입니다. 실제 가입이나 적립은 진행되지 않습니다.

확인한 증거

자동 테스트 60개 통과
중복 처리, 자기추천, 변경된 추천인, 월 10건 제한, 한국시간 월 경계, 여러 프로세스 동시 실행, 통신 실패, 지급 근거 불일치, 기존 입력값 보호를 검사했습니다. 실제 적립 내역 형식에 대한 검사 10개를 추가했습니다.
일반회원 추천인 코드
기존 일반회원 테스트계정에서 코드를 생성하고 아임웹 API에 저장된 것을 확인했습니다. 새 테스트 가입 후 전체 조회는 83명·2페이지로 완료했으며 가입 추천인 연결 1건을 확인했습니다.
소스 검사
모듈 구문 검사와 공백 검사를 통과했습니다. 테스트 HTML은 외부 CSS·JavaScript 없이 한 파일로 생성됩니다.

자동 테스트는 가상 데이터와 임시 원장을 이용합니다. 신규 일반회원 가입이나 실제 적립금 지급의 증거가 아닙니다. 실제 시험 적립·회수와 가입 기록은 아래 항목에서 별도 확인했습니다.

실제 적립·회수 검증

0원 → 3,000원 → 0원
승인된 일반회원 테스트계정 한 곳에만 지급하고 회수했습니다. 각 작업 전에 요청 미리보기를 확인했고 실제 증감은 한 번씩만 실행했습니다.
적립 1건, 회수 1건
아임웹 API에서 회원·사유·금액·통화·시간이 일치하는 +3,000원 및 -3,000원 내역을 각각 확인했습니다. 최종 잔액은 원래의 0원이며 회원그룹은 바뀌지 않았습니다.
지급 결과 대조 코드
실제 적립 내역 형식을 반영한 코드를 추가하고 해당 시험 적립 내역을 다시 읽어 확인했습니다. 별도 내역 ID가 없으므로 전체 조회 후 단 하나의 일치 내역인지 검사합니다.

이번 결과는 수동으로 승인한 적립·회수 검증입니다. 새 친구 가입으로 자동 적립됐다는 증거는 아닙니다. 회수는 내역 삭제가 아니므로 두 기록은 유지됩니다.

신규 가입부터 실제 지급까지

가입과 추천인 연결
사용자가 가입을 완료했습니다. 아임웹 전체 83명·2페이지 조회에서 새 테스트회원과 기존 테스트 초대자의 연결을 확인했습니다.
실제 프로그램 지급
추가 시험 승인을 받은 뒤 새 가입 기록과 전용 지급 원장으로 실행했습니다. 지급 시도 1회, 내역으로 확인된 지급 1건, 실패 0건이며 초대자 잔액은 3,000원이 됐습니다.
중복 지급 차단
같은 프로그램을 다시 실행했을 때 중복 1건으로 판정하고 추가 지급을 시도하지 않았습니다. 회수 후 원장을 새로 열어도 같은 결과였습니다.
전액 회수와 보존
즉시 3,000원을 회수하고 잔액 0원을 확인했습니다. 신규회원도 0원이고 두 회원의 그룹은 그대로입니다. 지급·회수 내역은 감사 기록으로 보존합니다.

수동 공급사 시험과 신규 가입 프로그램 시험은 각각 승인받은 별도 시험입니다. 이번 가입에는 추천인 코드를 직접 입력했고 작업 프로그램도 수동 실행했습니다. 공유 링크 자동 입력이나 예약 실행까지 검증했다는 의미는 아닙니다.

남은 검증과 필요한 승인

  1. 초대 링크를 열었을 때 가입폼에 코드가 자동 반영되는지와 소셜 가입 흐름을 확인해야 합니다. 필수 제3자 제공 항목의 예시 문구는 별도 정리가 필요합니다.
  2. 모바일·PC 화면 및 기존 일반회원 영상 이용 재검증. 현재 자동 브라우저가 로컬 파일 URL을 차단하여 시각 검증을 완료하지 못했습니다.
  3. 시작 일시, 원장 위치·백업, 실행 주기와 배포 범위 확정 후 한 가지 지급 방식만 활성화.

운영 영향과 저장 상태

실고객 적립금, 주문·회원그룹·영상 권한·내 강의실은 변경하지 않았습니다. 두 차례 시험 적립금은 모두 회수했습니다. 자체 위젯과 자동 적립은 배포하지 않았으며 예약 실행도 설치하지 않았습니다.

앞서 승인된 적립금 공통 설정과 무료체험 변경은 관리자 화면에 저장됐습니다. 상품별 별도 적립 설정은 아직 점검하지 않았습니다.

코드는 전용 작업 브랜치에 저장된 미커밋 상태입니다. CORE 운영규칙도 소스만 갱신했으며 라이브에는 반영하지 않았습니다. 테스트 브라우저 탭은 종료하고 기존 사용자 Chrome 탭은 보존했습니다.

휴대폰 인증이 없으므로 다른 이메일로 만든 동일인의 여러 계정까지 완전히 차단할 수는 없습니다.

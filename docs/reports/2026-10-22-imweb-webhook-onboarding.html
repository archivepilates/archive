ARCHIVE PILATES / 아임웹 앱·웹훅 연동 · 2026-10-22

샘플 수신 확인
사이트 연결·심사는 별도 진행

완료 보고가 아닙니다. 앱 인증정보 보관 승인과 사이트 접근 동의가 남아 있습니다. 기존 권한·상품·구매·정기 작업은 변경하지 않았습니다.

확인·적용한 것

  • 기존 ‘ARCHIVE PILATES 강사레슨 주문 연동’ 앱을 재사용했습니다. 회원 정보 읽기·쓰기 저장을 확인했고 앱을 중복 생성하지 않았습니다.
  • 가입·일괄가입·쇼핑 등급 변경 웹훅 3종을 테스트 상태로 등록하고 이벤트별 경로로 분리했습니다.
  • 새 수신 함수 imwebWebhookApi만 배포했습니다. 운영 회원 권한을 변경하는 함수나 기존 예약·알림톡 함수를 함께 배포하지 않았습니다.
  • 공식 가입 샘플의 실제 도착과 전달 구조를 확인했습니다. 인증 헤더를 포털 인증정보와 원문 노출 없이 대조했습니다.
  • 짧은 진단 수신은 종료했습니다. 정식 수신은 인증·자료형·사이트·유닛 검사와 중복 방지 후 그림자 원장에 저장하도록 준비했습니다.

아직 하지 않은 것

  • 기존 앱 Client ID·Secret의 Secret Manager 보관: 운영자 승인 대기.
  • OAuth 연결 기능: 보안 정책과 서버 소스 준비. 아직 함수로 내보내거나 배포하지 않았습니다.
  • 사이트 접근 동의·토큰 발급·테스트 사이트 연결 완료: 미수행.
  • 앱 심사 신청·승인·게시·실제 운영 웹훅 수신: 미완료. 담당 기관의 승인 여부는 별도입니다.
  • 웹훅에 따른 자동 권한 부여·회수 및 일반회원 접근 검증: 미전환. 기존 원천 재조회·40일·스텝 보호와 정기 점검을 유지합니다.

검증 경계

수신 프로토콜 25개, 별도 이벤트 정책 37개, OAuth 보안 정책 25개, CORE 패치 보호 3개, 배포 가드 20개, 시스템 상태 88개 테스트를 통과했습니다. TypeScript 중앙 빌드 및 최초 다섯 코드베이스 빌드·소유권 검사도 통과했습니다. 이 수치는 실제 심사 승인이나 일반회원 접근 증거가 아닙니다.

초기 CI의 고정된 함수 목록 검사를 새 수신 함수에 맞춰 명시적으로 보완했으며 후속 CI는 통과했습니다. 신규 함수의 실제 응답과 샘플 수신을 독립 확인했습니다.

보존·보안

수신 자료는 실행 권한이 아닌 원천 재조회 계기입니다. workLanes 원장으로 회원을 선정하거나 알림톡·StudioMate 쓰기를 실행하지 않습니다. 개인 구매·기존 공유권·원래 최초 부여 시각과 40일 만료·스텝 해제 보호를 보존합니다. 실제 회원 UID는 개인정보로 취급하며 관리자만 조회합니다.

인증정보 원문·쿠키·토큰·필터링하지 않은 요청 본문을 Git이나 보고서에 보관하지 않습니다. 동의 후 OAuth 토큰은 암호화할 예정이며 불명확한 발급 결과는 자동 재시도하지 않습니다. 추가 문의 메일이나 새 정기 자동화는 만들지 않았습니다.

다음 단계

  1. 운영자가 요청된 인증정보 보관 여부를 선택합니다.
  2. 승인된 범위만 설정·배포한 뒤 사이트 접근 동의 화면을 운영자에게 인계합니다.
  3. 테스트 연결·공식 샘플 3종을 확인하고 심사를 신청합니다.
  4. 승인 후 연동완료와 실제 이벤트를 검증한 다음, 기존 정본을 사용하는 권한 실행으로 제한 전환합니다.

아임웹 답변은 자체 사이트용 웹훅도 승인 가능하며 사용할 웹훅을 먼저 등록한 뒤 신청하라는 안내입니다. 같은 건으로 추가 문의를 보내지 않았습니다.

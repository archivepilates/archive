홈 화면 정리

사용자 승인 완료 · 수정·검증 후 CORE Hosting 운영 반영

삭제

  • 상세 목록과 연결되지 않는 ‘오늘 우선순위’ 합계와 설명
  • 상단 ‘오늘 할 일’ 문구와 불필요한 합계 계산 코드
  • 중복 설명과 사용하지 않는 요약 영역 스타일

유지·개선

  • 업무별 필요한 건수·바로가기와 재등록 목록은 유지합니다.
  • 조회 상태·조회 시각·새로고침은 작은 도구줄로 모읍니다.
  • 검색·빠른 실행·외부 도구를 재배치하고 모바일 2열 버튼과 운영 도구 간격을 정리합니다.
  • 조회 실패·한도 초과·원본 지연 안내와 접근성용 홈 제목은 유지합니다.

영향 범위

홈 화면 표시 변경입니다. 회원 데이터·로그인 권한·알림톡 대상과 승인·중복방지·자동화 주기는 변경하지 않습니다. 강사 계정의 홈 숨김도 유지합니다.

검증·배포

Node 회귀 57건과 Hosting·롤백 안전검사를 통과했습니다. 운영자·소유자 로그인 및 메뉴 이동 합성 검증 24조합, 정적 반응형 95건도 통과했습니다. 모바일·태블릿·PC에서 가로 넘침과 상단 계정 위치를 확인했고, 짧아진 화면에서 태블릿 상단이 늘어나는 현상도 보정했습니다. 운영 배포 결과는 완료 후 기록합니다.

홀딩 안내 전달 후 회원 메모 자동화

구현·무발송 검증 완료. 운영 반영과 실제 회원 전달·메모 반영은 구분해 확인합니다.

동작

새 홀딩 알림톡이 SOLAPI COMPLETE/4000으로 전달되고 후보·발송·선점 원장이 일치하면 계산 내역을 회원 메모 원본에 저장하고 기존 StudioMate 메모 쓰기 큐에 연결합니다. 기존 5분 주기 처리기가 브라우저 잠금 아래 메모를 추가하고 전체 내용과 고유 기록키를 재확인합니다.

합성 계산 예시이며 실제 회원에게 테스트로 추가하지 않았습니다. 여러 정지가 있으면 계산에 사용한 기간들을 함께 표시합니다.

안전장치

  • 접수 대기·실패·결과 불명확·테스트 발송은 메모를 만들지 않습니다.
  • 발송 건의 고정 키로 원본 메모와 작업을 함께 생성하며, 재실행·동시 실행에도 기존 완료/재시도 상태를 초기화하지 않습니다.
  • 회원·연결·계산·전달·내용이 맞지 않으면 보류하고 알립니다. 기존 메모는 삭제하거나 수정하지 않습니다.
  • 메모 실패는 메모만 재처리합니다. 알림톡은 다시 보내지 않습니다.
  • 기능 반영 이전의 발송분은 일괄 소급하지 않습니다. 다음 홀딩 계산에는 메모가 아닌 최신 StudioMate 원본을 사용합니다.

검증

홀딩·메모·운영메일 무발송 테스트 758건과 CORE 로컬 반응형 검사 95건 통과. 잘못된 원본 행의 격리·뒤 작업 진행, 회원 연결 변경 차단, 유한 재시도와 원장 조회 실패 알림도 검증했습니다. 격리 상태는 오래된 조회로 해제할 수 없고, 실패한 알림은 별도 대기로 보존합니다. 운영 Firestore의 제한된 대기·알림 조회는 읽기 전용으로 통과했습니다. 독립 코드 검토에서 남은 지적은 없습니다. Functions 영향은 0개로, 맥미니 처리기와 CORE Hosting 운영규칙만 반영 대상입니다.

운영 반영

독립 검토·커밋·main 승격·맥미니 반영·Hosting 배포·라이브 확인 대기.

실제 회원 대상 테스트 알림톡이나 메모 쓰기는 실행하지 않았습니다. 첫 자연 발생 건의 전달 완료와 StudioMate 메모 저장 결과는 별도 증거입니다.

확인된 원인

예정 정지는 Excel에서 사용 중으로 남아 정지명단에서 누락됐습니다. 원본의 예정 목록에는 저장돼 있지만 현재 정지 입력칸은 비어 있어 상세 검증도 중단됐습니다.

수정

  • 최근 수정된 유효 사용 수강권을 기존 시간별 동기화의 원본 읽기 대상으로 추가합니다.
  • 수정일이 날짜 단위이므로 새 정상 Excel마다 최근 변경을 재확인합니다. 같은 파일 재실행은 무시합니다.
  • 현재 날짜칸이 비어 있는 예정 정지는 취소되지 않은 생성 이력과 목록이 정확히 일치하고 대상이 하나일 때만 허용합니다.
  • 조회 대상의 우선순위를 보강하되 계속 정지 중인 대상의 순환 확인을 유지합니다.

보존한 안전장치

최초 계약기간 증거, 실제 등록시각 기준 48시간·전환일, 스텝 제외, 과거 기준선 무발송, 후보·발송·선점·SOLAPI 중복확인, 중도 해제·이력 불완전·초과 보류를 유지합니다. 조회 요청은 발송 원천이 아닙니다.

검증과 한계

새 회원목록 3,428행과 실제 예정 정지를 읽기 전용으로 대조했습니다. 원본 ID가 없는 대상은 보류합니다. 사전검증은 발송 증거가 아니며, 실제 정기 실행의 전달 완료는 SOLAPI와 원장 일치로 판정합니다.

배포 대상: 맥미니 운영 실행기, CORE 운영규칙 Hosting. Functions·Firestore 규칙·주기는 변경하지 않습니다. 실제 릴리스 식별자는 CORE release.json과 Git 기록을 따릅니다.

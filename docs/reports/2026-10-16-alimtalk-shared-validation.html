기존 Firestore를 유지하고 일반 발송 큐, 강사레슨 승인 발송, CORE와 MCP가 같은 검증 정책을 사용하도록 연결했습니다. 새 종합 DB·스케줄러·발송 실행기는 없습니다.

사용 방법

CORE 알림톡 메뉴에서 최근 후보를 펼쳐 검증을 누르거나 정확한 후보 ID를 입력합니다. MCP는 messages_validate_target({candidateId})로 조회합니다.

운영자만 사용할 수 있습니다. 결과의 조회시각은 StudioMate 실시간 확인시각이 아니며 allowedForExternalActions=false입니다. 사전검증은 승인·발송·재시도 권한이 아닙니다.

유지한 운영 규칙

  • 기존 대상 선정, 대량 승인, 근무 스텝 제외, 템플릿별 중복 기간과 승인된 단건 테스트 예외를 유지합니다.
  • 일반 큐와 강사레슨 승인 실행기의 함수 본문은 기존 배포본과 동일하며 검증 import만 공통 경로로 연결합니다.
  • 기존 발송 원장·시도·불명확한 결과가 있으면 자동 재발송 대상으로 표시하지 않습니다.
  • 조회는 후보·원장·템플릿 상태를 변경하지 않습니다. 10분 이내 템플릿 증거가 없으면 추가 확인으로 남깁니다.
  • 홀딩, 계약완료 웰컴, 강사레슨, 그룹 설문, 리포트의 전용 최종 검증은 기존 실행기에 남기고 사전검증과 구분합니다.
  • 전체 회원·예약·수업을 새로 재계산하지 않고 요청된 후보만 순차 확인합니다. 기존 회원별 중복 이력의 조회 기간을 임의로 줄이지 않습니다.

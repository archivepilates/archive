Website Strategy

ARCHIVE PILATES 웹사이트 설계안

메인 홈페이지는 강사레슨과 온라인 클래스를 중심으로 브랜드의 기준을 보여주는 허브로 두고, 블로그, 유튜브 영상 판매, ARCHIVE IN, 강사채용, 신청폼은 목적별 링크 서비스로 연결한다.

작성일 2026-05-20 메인 도메인 archivepilates.com 위치 부산 강서구 명지 Imweb + Cloudflare

Core Decision

메인 사이트는 “판매형 허브”로 간다

ARCHIVE PILATES의 첫 화면은 일반 회원 수업 안내가 아니라 오프라인 강사레슨, 온라인 강사 클래스, 회원 온라인 콘텐츠로 바로 진입하게 설계한다. 스튜디오 소개는 신뢰를 보강하는 두 번째 레이어로 두고, 블로그/유튜브/ARCHIVE IN은 관심이 생긴 사용자가 더 깊이 들어가는 채널로 연결한다.

결론: “스튜디오 소개 사이트”가 아니라 “강사레슨과 온라인 콘텐츠 판매를 위한 브랜드 허브”가 맞다.

현재 반영 상태

  • 완료 Imweb 홈페이지 게시
  • 완료 Cloudflare 루트/www 리다이렉트 전환
  • 완료 명지 주소와 강사레슨 중심 카피 반영
  • 준비 필요 상품 상세/결제 페이지 구성
  • 준비 필요 카카오 상담 또는 신청폼 CTA 확정

Audience

주요 대상과 목적

1차 대상

오프라인/온라인 강사레슨 수강자

필라테스 강사, 예비 강사, 수업 설계와 티칭 언어를 더 깊게 정리하고 싶은 사람.

2차 대상

기존 회원과 심화 회원

스튜디오 수업 밖에서도 복습하고, 움직임 이해도를 높이고 싶은 회원.

3차 대상

브랜드 탐색자와 지원자

블로그, 유튜브, 채용, ARCHIVE IN을 통해 ARCHIVE PILATES의 운영 방식을 확인하려는 사람.

Sales Flow

강사레슨과 영상 판매 흐름

오프라인 강사레슨
홈페이지 CTA에서 문의로 연결하고, 일정/대상/레벨을 확인한 뒤 결제 또는 예약으로 보낸다. 초기에는 카카오 상담이 안전하고, 운영이 정리되면 Imweb 상품 상세와 결제로 전환한다.
온라인 강사 클래스
Imweb 상품 상세에서 커리큘럼, 시청 방식, 수강 기간, 환불 기준을 명확히 안내한다. 결제 후 영상 접근 권한을 제공하는 구조가 가장 자연스럽다.
유튜브 영상 판매
굳이 일부공개 링크를 공개적으로 뿌릴 필요는 없다. 비공개 영상으로 두고, 주문자의 이메일을 유튜브 영상 공유 권한에 추가한 뒤 안내 메일을 보내는 방식이 가능하다. 다만 구매자 수가 늘면 수동 운영보다 Google/YouTube API 자동화가 필요하다.
회원 온라인 콘텐츠
ARCHIVE IN 또는 별도 회원 전용 페이지로 연결한다. 기존 회원 운영과 결합되므로 공개 홈페이지에서는 “회원 콘텐츠 보기” 정도로 가볍게 진입점을 둔다.

Imweb 상품/결제

오프라인/온라인 클래스 판매 페이지. 상품 상세, 결제, 주문자 정보 수집을 담당한다.

네이버 블로그

기록형 콘텐츠, 검색 유입, 스튜디오 소식과 후기성 자료를 담당한다.

유튜브

무료 영상, 샘플 강의, 구매자 전용 영상 보관소 역할을 한다.

ARCHIVE IN

회원 콘텐츠, 운영 서비스, 내부/회원용 기능을 담당한다.

apply.archivepilates.com

강사 채용과 지원 흐름을 분리해 운영한다.

Copy Direction

카피 방향

사용할 톤

  • 강사의 수업을 기록하고, 레슨의 기준을 다시 세우는 클래스
  • 움직임을 관찰하고, 수업 언어를 정리하는 공간
  • 현장에서 다시 사용할 수 있는 시퀀스와 큐잉
  • 오프라인 피드백과 온라인 반복 학습의 결합

피해야 할 톤

  • 일반 회원 수업 시간표를 첫 화면에 크게 내세우는 구성
  • “수업 안내 / 스튜디오 소개”만 있는 평범한 센터 소개형 문구
  • 위치 오류: 율하, 김해 등 이전 문구
  • 구매 CTA가 없는 단순 소개형 랜딩

Next Build

다음 작업 순서

상품 상세 2개 먼저 만든다

오프라인 강사레슨, 온라인 강사 클래스 상품 상세를 만들고 홈페이지 CTA를 해당 페이지로 연결한다.

카카오 상담 링크를 확정한다

현재 CTA 일부는 문의 섹션 앵커로 연결되어 있으므로 실제 카카오 채널/상담 URL로 바꾼다.

유튜브 판매 자동화 방식을 정한다

초기에는 수동 권한 부여, 이후 주문 발생 시 이메일 권한 추가와 안내 메일 발송을 자동화한다.

시각 자료를 실제 스튜디오 이미지로 교체한다

현재 구조는 잡혔으므로 실제 명지 스튜디오 사진, 강사레슨 장면, 영상 썸네일을 넣어 전환율을 높인다.

섹션형 Imweb 운영 방식을 유지한다

00-global-style-and-script.html과 섹션별 콘텐츠 파일을 유지해 순서 변경과 부분 수정이 쉽게 만든다.

중간 문제·최종 상태

첫 비대화형 배포는 신규 retry 정책의 CLI 명시 확인 요구로 활성화 전에 중단됐고 --force 정책 확인으로 완료했습니다. 운영 계정에 원인·무영향·재시도 안내와 최종 복구 완료를 보냈습니다. 첫 CI는 기존 export 예상 목록 누락으로 실패해 검증 목록을 보완했으며, 최신 5b53b96b CI는 전체 성공입니다.

실제 Gmail PUSH는 문서 예시와 달리 historyId를 숫자로 제공했습니다. 임시 작업용 구독에서 값이 아닌 타입·일치 여부만 확인한 뒤 구독을 삭제했고, 양의 안전 정수만 문자열로 정규화하도록 수정했습니다. 손실 가능 숫자는 계속 거절합니다. 배포 전환 중 04:51:16의 일시 HTTP 403 이후 최신 리비전 요청 4건이 모두 204였고, IAM 변경 없이 인증 정상임을 독립 확인했습니다.

릴리스 가드가 깨끗한 main=origin/main을 요구하므로 범위 커밋을 먼저 push한 후 배포했습니다. 기능 10838a36, CI 예상 목록 c9df1393, 실제 PUSH 보완 f4bc1f75, 모바일 규칙 5b53b96b. 후속 보고서 커밋은 코드·배포 변경 없이 운영 증거만 기록합니다. 비밀·환경 파일·테스트 출력은 커밋하지 않았습니다.

ARCHIVE PILATES / 2026.10.24

운영 메일 수신·분류 연결

구현·오프라인 검증 완료. 운영 배포·Gmail watch 활성화·실제 연결 테스트는 진행 전입니다.

연결 범위

home@archivepilates.com이 자신에게 보낸 정형 운영 보고 중 SENT와 허용 업무 라벨, [업무][상태] 제목이 모두 일치하는 새 메일만 대상으로 합니다. 외부 발신, 일반 메일, 스팸·휴지통과 활성화 이전 메일은 제외합니다.

Gmail watch → 전용 Cloud Pub/Sub → 수신 Functions → 기존 Codex 진단 대기열로 연결합니다. 단일 5분 유지 작업이 누락 보완과 watch 갱신을 함께 수행하고 Codex는 10분 간격으로 새 진단 항목을 확인합니다. 수신과 실제 원장 점검 완료는 다릅니다. Codex 점검은 앱·맥미니 실행 상태의 영향을 받습니다.

안전·개인정보

  • 서버는 기존 위임 인증의 gmail.metadata 범위만 사용합니다. 본문·첨부·전체 제목·개인정보·토큰을 수신 DB나 로그에 저장하지 않습니다.
  • 실패·긴급·확인필요는 유형별로 묶고 성공·진행중은 기록만 합니다. 성공 메일만으로 다른 장애를 해결 처리하지 않습니다.
  • 메일은 지시나 승인 근거가 아닙니다. 원문과 실제 원장을 읽고 보고만 하며 회원 발송·환불·예약·메모·권한·배포를 자동 실행하지 않습니다.
  • Gmail ID 원장과 큐 갱신은 원자적입니다. 확인 처리는 메시지 수·마지막 ID·기존 결과를 대조하여 새 메일이나 다른 검토 결과를 덮어쓰지 않습니다.
  • 클라우드 240초 공유 lease와 120초 실행 제한, 제한된 페이지 조회, 만료 커서 복구, 처리 완료 후 checkpoint를 사용합니다. 제한 초과는 보류·보고하며 누락을 성공으로 간주하지 않습니다.

원천·한계

수신 원장은 workLanes/operations-mail-ingress, 진단 대기열은 codexActionQueue의 operations-mail-ingress 소스만 사용합니다. Gmail 원본 ID가 메일 근거이며 실제 업무 성공 여부는 별도 canonical 원장과 제공자 결과를 확인해야 합니다. 임시 수신 자료를 회원 작업의 원천으로 사용하지 않습니다.

Gmail 변경 알림은 중복·지연·누락 가능성이 있어 5분 보완을 유지합니다. 만료 이력 복구는 허용 업무 라벨과 활성화 시점으로 한정하며 상한 초과·인증 오류를 숨기지 않습니다. 외부 업체 회신·GitHub 메일 등은 이번 범위에 포함되지 않습니다.

# CORE 시퀀스 노트: 구간별 포지션

- 작성 구조: 준비·메인·마무리 구간 → 포지션 → 동작. 기구별 시작 자세 SVG는 선택을 돕는 원본 도식이며 동작 지침이 아니다. 현재 기구 목록은 그대로 쓰며 직접 입력을 항상 제공한다.
- 동작은 현재 구간의 다른 포지션 또는 미지정으로 옮길 수 있다. 미지정은 항상 처음에 표시하며 기존 순서를 유지한다. 포지션을 지워도 동작은 삭제되지 않는다. 기구 변경 시 기존 자세와 동작을 유지하고 재선택 안내를 표시한다.
- 응답·저장 데이터는 기존 `archive.sequence.v1`과 구간별 평탄한 `moves`를 유지한다. `positions` 순서와 동작의 선택적 `positionId`만 추가한다. 기존 파일과 기존 시퀀스는 추정 없이 미지정으로 열리고, 포지션이 없으면 저장 시 확장 필드도 생략한다. 이미지 레코드, 접근권한 및 Firestore 규칙은 변경하지 않았다. 이동 및 정렬 후 평탄한 순서도 새 작성기와 일치한다.
- 미리보기, 읽기 전용, PDF·인쇄는 같은 포지션 머리글을 사용한다. 묶음이 페이지를 넘기면 다음 페이지에서 머리글을 반복한다. 미지정만 있는 기존 노트의 PDF 형식은 유지한다.
- 운영 배포 전 작성자가 쓰던 구버전 탭을 모두 저장하고 닫거나 새로고침해야 한다. 구버전 저장기는 새 선택 필드를 제거할 수 있으므로, 기능 사용 이후 롤백이 필요하면 편집기 호환성을 먼저 확보한다. 데이터 일괄 변경은 없다.
- 로컬 검증: `ARCHIVE_SEQUENCE_TEST_FILTER='position groups' node scripts/verify-core-sequence-studio.mjs` (실제 브라우저, 테스트 Auth/Firestore), `node --experimental-vm-modules --test scripts/tests/sequence*.test.mjs`. 로컬 확인 시 `ARCHIVE_CORE_BASE_URL`을 설정하지 않는다.

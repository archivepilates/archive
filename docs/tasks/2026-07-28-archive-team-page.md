# 팀아카이브 소개 페이지 개편

- 상태: 로컬 구현 및 반응형 검증 완료
- 기준 페이지: PURE Yoga 강사 목록과 개별 프로필
- 적용 원칙: 사진 중심 목록, 관점 우선 상세, 자격 이력 접기
- 원천: 공개 팀아카이브 프로필
- 개인정보: 연락처와 내부 운영 정보 제외

## 구현

- 공식 홈페이지의 외부 팀 노션 링크를 `/teams` 내부 페이지로 변경
- 팀 목록과 5명 개별 프로필 페이지 구성
- 모바일 터치 환경에서 영문 메뉴 전환을 비활성화해 메뉴 떨림 방지
- 검색 노출을 위한 canonical, Open Graph, Person 구조화 데이터, sitemap 추가
- Firebase `/teams` rewrite를 새 디렉터리형 목록 페이지로 변경

- 목록과 상세 페이지의 이미지 로드 실패 0건

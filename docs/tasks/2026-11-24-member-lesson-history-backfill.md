# 회원별 수강 이력의 Supabase 보관

- 범위는 2025-01-01부터 2026-11-24까지의 ARCHIVE PILATES 수강 예약 기록입니다. 이름·연락처·회원 원본 ID·회차권 상태·결제와 환불은 이 복제본의 항목에 포함하지 않습니다. 같은 회원 키로 관리자 환경에서 인바디 결과를 대조할 수 있습니다.
- 2025-01-01~2026-05-26은 StudioMate의 회원별 이용내역 엑셀 보관본, 2026-05-27~2026-11-24는 StudioMate 전체 예약 화면과 공식 예약 엑셀을 일대일 또는 동일 키의 개수로 대조한 원본을 사용했습니다. 전자는 원본 회원 URL과 기존 내보내기 기록, 후자는 원본 회원 ID·예약 ID·수업 ID를 검증합니다.
- 날짜, 수업 시작·종료, 예약 상태와 확인된 정규 수업 유형만 보관합니다. 그룹·프라이빗이 원본에 없는 보관 행은 원본 엑셀끼리 확실하게 대조된 경우만 채웠습니다. 추정 유형은 보관하지 않습니다.
- 용도는 관리자 분석입니다. 운영팀의 현재 예약·승인·발송·결제는 기존 원본을 사용합니다. 예전 Supabase 수강권 연결 자료를 함께 더하면 중복되므로, 같은 기간 출석을 집계할 때는 `archive_lesson_history.booking`을 기준으로 합니다. 기존 회원별 MCP 조회 범위는 그대로 유지합니다.
- 대상은 Supabase 회원 이력 프로젝트의 비공개 `archive_lesson_history`입니다. 날짜 범위가 겹치는 배치, 중복 예약 키, 원본 해시가 달라진 적재는 차단합니다. 이번 적재 계정은 원본 테이블 열람·수정 권한이 없으며 작업 후 비활성화합니다.

2026-11-24 검증. 날짜 누락 0일, 배치 24개, 638명·43,506건입니다. 2025년 22,693건, 2026년 20,813건이며 출석 25,197건을 포함합니다. 수업 유형 미확인 25,632건은 미분류로 남겼습니다. 배치별 승인 원본 크기, 예약 상태별 건수, 적재 결과를 새 연결로 대조했고 단일 인바디 연결 키로 해당 회원의 수강 이력을 조회할 수 있는지 확인했습니다.

비공개 운영 증빙은 맥 미니 운영 데이터의 `operations/2026-11-24-lesson-history-import`에 둡니다. 보관본과 적재 파일의 해시를 확인한 뒤 쓰고, 확인되지 않은 저장은 DB 영수증을 다시 읽어 판정합니다.

# 아임웹 판매영상 제작 흐름 정규화

## 지연 원인

- 같은 영상 정보를 내 강의실, 영상구매 목록, 추천 연결, 버전 로더, 검증 코드에 반복 입력했다.
- ACA6·ACH9 숨김 페이지가 아임웹 기본 영상 위젯을 사용했지만 기존 내 강의실 판별기는 커스텀 임베드만 인식했다.
- 공식 홈페이지 자산과 아임웹 로더의 배포 순서가 분리되어 중간 상태에서 검증 실패가 발생했다.
- 아임웹 전역 스크립트 수정량 제한 때문에 일반 CLI 쓰기 대신 검증된 대용량 적용 절차가 필요했다.
- 원본 2편과 미리보기 2편의 유튜브 업로드·처리 및 메타데이터 정리가 함께 진행됐다.
- 상품 2개에 대해 상품, 그룹, 숨김 페이지, 미리보기, 구매자·비구매자 모바일/PC를 각각 확인했다.

# ARCHIVE PILATES 아임웹 첫 화면 위치 안정화

## 문제

- 첫 화면 원본 `.apb-hero-text`는 `apbHeroIn` 애니메이션으로 `translateY(-20px)`에서 `translateY(-48px)`로 이동한다.
- Footer의 모바일 로고·히어로 정렬 스크립트는 데스크톱에서 같은 요소를 `translateY(48px)`로 다시 지정한다.
- 두 규칙이 서로 다른 시점에 적용되어 텍스트가 위쪽에 먼저 보인 뒤 최종 중앙 위치로 이동한다.

## 수정

- Header 전역 개선 블록을 `2026-08-31a`로 갱신한다.
- 데스크톱 첫 페인트부터 최종 `translate3d(0,48px,0)` 위치를 사용한다.
- 첫 화면 텍스트의 애니메이션과 transition만 제거한다.
- 모바일과 아래 섹션의 reveal 애니메이션은 변경하지 않는다.

## 검증

- 관리자 저장 알림 `내용을 정상적으로 저장했어요` 확인
- 관리자 새로고침 후 Header 값과 준비본 완전 일치, `2026-08-31a` 블록 1개 확인
- 1440px 새로고침 직후 1ms부터 2.5초까지 Y좌표 `273.14px` 고정
- 1024px 새로고침 직후 0~1.8초까지 Y좌표 `267.41px` 고정
- 데스크톱 히어로 텍스트 `animation: none`, `transition: none`, `translateY(48px)` 확인
- 320px, 390px, 768px 가로 넘침 0, 모바일·태블릿 기존 전환 유지
- 공개 페이지 콘솔 error·warning 0

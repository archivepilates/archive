# 수동 영상 구매자 공식 사이트 안내

## 목적

- 공식 사이트 개설과 온라인 영상 구매·시청 흐름을 기존 수동 구매자에게 안내한다.
- 수신자 개인정보는 작업 문서와 Git에 기록하지 않는다.

## 안내 페이지

- URL: `https://archivepilates.com/video-guide`
- 흐름: 회원가입·로그인 -> 기구별 영상 선택·결제 -> 내 강의실에서 40일 시청
- 연결: 영상구매 `/videos`, 내 강의실 `/my-classroom`, 카카오 문의
- 기존 `/my-classroom` 리다이렉트의 잘못된 `/my-page` 목적지를 실제 아임웹 내 강의실 `/48`로 수정한다.

## 발송 기준

- Notion `유료영상 구매자 리스트`를 원천으로 사용한다.
- 이메일은 정규화 후 중복 제거한다.
- 목록에는 광고 수신 동의 기록이 없으므로 전원을 대상으로 발송하지 않는다.
- 최근 동일상품 거래 예외 범위와 수신거부 이력을 확인해 발송 적격자만 선정한다.
- 메일 제목에 `(광고)`를 표시하고, 전송자 정보와 회신 방식의 수신거부 안내를 본문에 포함한다.
- 실제 고객 발송 전 운영자 계정으로 테스트 메일을 보내 링크와 표시를 확인한다.

## 검증

- 모바일 320px, 390px, 태블릿, 데스크톱 화면에서 가로 넘침과 CTA 동작을 확인한다.
- 배포 후 페이지 HTTP 200, canonical, 영상구매·내 강의실·카카오 링크를 확인한다.
- Gmail 보낸편지함에서 테스트 메일과 실제 발송 결과를 확인한다.

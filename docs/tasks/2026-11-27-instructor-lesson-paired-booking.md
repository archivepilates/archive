- Canonical action: the existing date/studio/phone registration and issuance job. Both store the same booking-policy marker and the manager's one-request StudioMate daily-limit acknowledgement. No new scheduler or member transport.
- The existing Mac mini worker verifies the issued 2T pass, all current member classes and the exact pass's booking list, then reads the full same-date StudioMate ticket wizard. It selects one group with seats in both non-overlapping slots. If a matching reservation already exists it stays in that group.

# 수강생 공유영상 시청 분석

## 목적

- 2026년 8월 강사레슨 수강생 공유영상의 실제 이용 여부를 ARCHIVE CORE에서 확인한다.
- 판매영상 통계와 수강생 공유영상 통계를 섞지 않는다.
- 아임웹 회원그룹, 영상 접근 권한, 내 강의실 목록, 구매·환불 흐름은 변경하지 않는다.

## 허용 범위

- 판매영상: 기존 `/archive-method-watch-*`
- 수강생 공유 A팀: `/private-lesson-support-movement-a-260829` → `A260829`
- 수강생 공유 B팀: `/private-lesson-support-movement-b-260829` → `B260829`
- 수강생 공유 C팀: `/private-lesson-support-movement-c-260830` → `C260830`
- 수강생 공유 D팀: `/private-lesson-support-movement-d-260830` → `D260830` (B팀 영상 대체)
- 위 네 경로 이외의 프라이빗 페이지, 공개 미리보기, 상품 페이지는 추적하지 않는다.

## 구현

- 브라우저 추적기가 허용 경로에서만 `paid` 또는 `student_share` 유형을 전송한다.
- 수집 API가 페이지 경로와 영상 코드를 기준으로 유형을 다시 판정하고 불일치 요청을 거부한다.
- 기존 유형 필드가 없는 세션은 원래 페이지 경로로 판매영상 또는 수강생 공유를 판정한다.
- ARCHIVE CORE 영상 시청 현황에 `판매영상 / 수강생 공유` 전환을 추가하고 기본값은 판매영상으로 유지한다.
- 화면의 시청 횟수는 30분 기준 세션 수로 표시하고, 재생 전환 횟수는 조회수처럼 오해되지 않도록 노출하지 않는다. 완료 표시는 `90% 도달`로 정리한다.
- 개인정보처리방침과 ARCHIVE CORE 운영규칙에 수강생 공유영상 시청 분석 범위를 반영한다.

## 데이터 원칙

- 원천: `videoWatchEvents`
- 계산 미러: `videoWatchSessions`
- 유형: `paid`, `student_share`
- 상세 이벤트에는 회원 이름을 저장하지 않고 세션 요약에 정제된 회원 이름만 저장한다.
- 전화번호와 원문 이메일은 저장하지 않는다.
- 시청 데이터는 구매, 그룹 권한, 환불, 자동 메시지 대상을 변경하는 원천으로 사용하지 않는다.
- 추적 실패는 YouTube 재생과 기존 페이지 접근을 막지 않는다.

## 상태

- `implemented locally`: 추적기, 수집 API, 분리 집계, ARCHIVE CORE 전환 UI
- `pending`: 자동 테스트, Functions 빌드, Hosting 검증, 320/390/768/1440px 반응형 검증
- `not deployed`: 사용자 배포 승인 전에는 Functions, Hosting, 아임웹 body script를 변경하지 않는다.

## 배포 순서

1. Functions app codebase를 먼저 배포한다.
2. 새 추적기 정적 파일과 ARCHIVE CORE, 개인정보처리방침 Hosting을 배포한다.
3. 새 정적 파일 응답과 해시를 확인한다.
4. 아임웹 body의 기존 스크립트를 보존하면서 추적기 로더 한 개만 새 버전으로 교체한다.
5. 판매영상 권한 회원, 수강생 공유 권한 회원, 무권한 일반회원으로 접근과 재생을 검증한다.
6. 수강생 공유 테스트 이벤트가 ARCHIVE CORE의 `수강생 공유`에서만 보이고 판매영상에는 섞이지 않는지 확인한다.

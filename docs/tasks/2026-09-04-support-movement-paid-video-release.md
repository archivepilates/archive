# 지지와 움직임 판매영상 등록

## 대상

- ACA6: 캐딜락 지지와 움직임, 상품 84, 40일 이용권
- ACH9: 체어 지지와 움직임, 상품 85, 40일 이용권

## 구성

- 각 상품은 별도 회원그룹과 숨김 시청 페이지를 사용한다.
- 상품 상세에는 해당 영상의 공개 미리보기만 표시한다.
- 판매용 전체 영상은 각 숨김 시청 페이지의 페이지 전용 위젯에만 둔다.
- 내 강의실은 회원그룹 권한을 확인해 해당 카드만 표시한다.
- 내 강의실은 기존 코드형 임베드와 아임웹 네이티브 영상 위젯을 모두 권한 페이지로 판별한다.
- 시청 추적기는 `/archive-method-watch-*` 규칙으로 두 신규 영상을 판매영상으로 자동 분류한다.

## 검증

- 상품명, 가격 15,000원, 판매 상태, 40일 이용권, 카테고리, 썸네일을 API로 재조회한다.
- 로그아웃 사용자는 두 시청 페이지에서 로그인 화면으로 이동하고 전체 영상이 노출되지 않아야 한다.
- 일반 구매자 테스트 회원은 모바일과 PC에서 ACA6·ACH9 카드를 보고 영상을 열 수 있어야 한다.
- 무권한 일반회원은 두 카드와 영상에 접근할 수 없어야 한다.
- 테스트 그룹은 검증 후 원래 값으로 복구하고 API로 재확인한다.

## 완료 결과

- 공식 홈페이지 Hosting 자산 `2026-09-04c`와 아임웹 로더 `2026-09-04d`를 배포했다.
- 비로그인 사용자의 내 강의실 및 신규 시청 페이지 접근은 로그인 화면으로 전환됨을 확인했다.
- 일반 구매자 테스트 회원은 모바일과 PC에서 기존 비판매 수업 4편과 ACA6·ACH9를 모두 확인하고 각 시청 페이지를 열었다.
- 일반 비구매자 테스트 회원은 모바일과 PC에서 카드가 0개이고 보호 영상도 열 수 없음을 확인했다.
- 테스트에 사용한 구매자 그룹은 원래 값으로 복구했고 API 재조회 결과가 일치했다.
- 일반회원 사이트 스모크 테스트는 320px, 390px, 태블릿, PC의 28개 항목에서 오류와 경고 없이 통과했다.

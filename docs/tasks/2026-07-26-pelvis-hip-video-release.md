# 2026-07-25 골반·고관절 강사레슨 영상 운영

Date: 2026-07-26

## 확정 매핑

- A팀 은영 리포머: 판매 상품 `AR5`, 상품 번호 `80`.
- A팀 민진 바렐: 판매 상품 `AB9`, 상품 번호 `79`.
- B팀 은영 리포머: 비판매 수업 공유 영상.
- B팀 민진 바렐: 비판매 수업 공유 영상.
- 파일명보다 실제 수업 팀 확인을 우선한다. 이번 민진 바렐 영상은 실제 장면 기준으로 A/B팀을 정정했다.

## 구현

- A팀 영상은 YouTube 일부공개, 판매용 재생목록, 아임웹 이용권 상품, 40일 회원그룹, 구매자 전용 시청 페이지로 연결했다.
- B팀 영상은 판매 상품과 공개 카테고리를 만들지 않고, 단일 비공개 수업 그룹과 두 개의 숨김 시청 페이지로 연결했다.
- 기존 가입 B팀 회원 3명에게 비공개 수업 그룹을 추가했다. 미가입 2명은 가입 후 같은 그룹을 부여한다.
- `내 강의실` 자산에 `AB9`, `AR5`, B팀 바렐·리포머 카드를 추가했다.

## 접근 검증

- 비회원: 4개 시청 페이지 모두 차단 `4/4`.
- 로그인한 미구매 회원: 4개 시청 페이지 모두 차단 `4/4`.
- `AB9` 그룹: AB9만 허용 `4/4`.
- `AR5` 그룹: AR5만 허용 `4/4`.
- B팀 비공개 그룹: B팀 두 페이지만 허용 `4/4`.
- 테스트 회원의 임시 그룹은 검증 후 원래 상태로 복구했다.

## 배포 및 라이브 확인

- Firebase Hosting `archive-pilates-home`에 내 강의실 자산을 배포했다.
- 아임웹 헤더 스크립트의 자산 버전을 `20260726a`로 갱신하고 readback으로 확인했다.
- `/48` 모바일 라이브 확인:
  - 비회원은 로그인 화면으로 이동한다.
  - 미구매 회원은 빈 상태만 표시된다.
  - `AB9` 그룹은 AB9 카드 1개만 표시된다.
  - `AR5` 그룹은 AR5 카드 1개만 표시된다.
  - B팀 그룹은 바렐·리포머 카드 2개만 표시된다.
  - 아임웹 기본 헤더·푸터가 노출되지 않고 가로 넘침이 없다.
- 상품 `79`, `80` 공개 상세 페이지는 HTTP `200`이며 올바른 A팀 썸네일을 표시한다.

## 반복 작업 기준

1. 배정표와 실제 영상 장면으로 팀·강사·기구를 확정한다.
2. 판매 영상만 상품, 판매 재생목록, 판매 카테고리에 연결한다.
3. 비판매 수업 영상은 별도 그룹과 숨김 페이지로만 제공한다.
4. 내 강의실 자산과 외부 스크립트 버전을 함께 갱신한다.
5. 비회원, 미구매 회원, 각 권한 그룹의 허용·차단 매트릭스를 검증한다.
6. 테스트용 임시 그룹이 원상복구됐는지 확인한다.

- StudioMate 당일 출석 명단을 원천으로 사용하고 결석자는 권한 대상에서 제외한다.

## 권한 원칙

- 아임웹 팀 전용 회원그룹으로 페이지 접근을 제한한다.
- 같은 회원의 기존 그룹은 유지하고 새 팀 그룹만 추가한다.
- 이름과 전화번호가 모두 일치하는 현재 출석 회원만 자동 반영한다.
- 동명이인·중복 계정·미가입 회원은 로그인 이력과 기존 그룹을 확인하거나 가입 후 별도 반영한다.

## 배포와 검증

1. YouTube에 네 영상을 일부 공개로 업로드하고 수강생 공유용 재생목록에 분리한다.
2. 아임웹에 A·B팀 숨김 페이지와 전용 그룹을 만들고 각 페이지에 두 영상을 연결한다.
3. Functions의 허용 경로, CORE 추적 자산과 운영규칙을 배포한다.
4. 팀 권한 일반회원은 해당 팀 두 편만, 무권한 일반회원은 어떤 영상도 보지 못하는지 모바일·PC에서 확인한다.

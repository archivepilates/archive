홈페이지 강사레슨 자동접수

2026-09-27 · 승인 범위: 자동화 연결·운영 반영·이번 주문 처리. 수업 예약은 생성하지 않습니다.

원천과 실행 경로

아임웹 공식 주문 API의 결제·품목·수강일·주문자 연락처가 구매 원천입니다. 메일 문구를 발급 근거로 사용하지 않습니다. 수강권·가입서·알림톡 실행 원천은 기존 instructorLessonRegistrations와 studiomateInstructorLessonJobs입니다.

imwebInstructorLessonOrders는 주문 중복 방지·처리 이력 장부입니다. 회원 CRM 미러가 아니며, 장부만으로 외부 발급·발송하지 않습니다. 운영 서비스계정만 읽고 씁니다. 기존 보안 규칙에서 일반 클라이언트 접근은 허용하지 않습니다.

식별과 안전장치

  • 주문번호·품목번호로 원본을 추적하고, 스튜디오+휴대폰+수강일 해시로 기존 수동 접수까지 중복 검사합니다.
  • 기존 수동 접수나 다른 주문이 만든 등록은 변경하지 않습니다. 동일일 기존 수강권이 발견되면 결제 연결 검토 전 발급하지 않습니다.
  • 현재 허용 상품: 오프라인 ARCHIVE METHOD 강사레슨 상품 1. 1인, 선물 아님, 미래 수강일, 카드 70,000원, 포인트·배송비 없음. 할인·복수인원·다른 결제수단·다른 상품은 자동 발급하지 않습니다.
  • 활성화 이전 결제는 제외합니다. 최근 30일 주문을 완전 페이지 조회하며 500건 상한을 넘으면 발급 없이 확인필요로 남깁니다. 이미 접수한 주문은 수강일까지 계속 확인합니다.
  • 정원은 최대 10명이며 수업 정원이 더 적으면 그 값을 적용합니다. 현재 수강권 원천, 접수 원장, 활성 예약을 전화번호 기준으로 합산합니다. 수업 미생성은 중단 사유가 아닙니다.
  • 등록 직전·수강권 발급 직전에 주문을 다시 읽습니다. 취소·환불·수강자·날짜·금액 변경 시 중단하고 기존 알림톡의 입금 확인 조건을 해제합니다. 발급된 수강권은 자동 삭제·환불하지 않습니다.
  • 결제 화면의 판매가·결제금액·카드금액·미수금·기타 결제수단을 확인하고 발급 후 수강권 금액을 재확인합니다. 홈페이지 재청구는 하지 않습니다. 같은 구매의 아임웹 매출과 StudioMate 기록은 합산 금지입니다.

운영과 예외

새 Cloud Scheduler나 Codex 하트비트 없이 기존 Mac mini 등록 LaunchAgent에 연결합니다. 등록 큐의 2분 주기는 유지하고 주문 조회는 로컬 체크포인트로 10분 간격 제한합니다. 프로세스 소유 잠금과 죽은 소유자 복구를 사용합니다. 실질 변경 없는 주문은 Firestore 반복 쓰기를 생략합니다.

확인필요는 CORE 등록 단계·자동화 관제와 운영 메일에 남깁니다. 고객의 실제 가입서 서명은 자동화가 대신하지 않습니다. 신규 회원은 가입서 서명·메모 반영 완료 전까지 완료로 표시하지 않습니다.

검증 및 배포

합성 주문 정책 테스트, 모의 DB 트랜잭션 테스트, 원본 읽기 전용 dry-run, StudioMate 금액 UI 무저장 확인 후 제한 적용합니다. 기존 등록·가입서·예약확정 안내의 중복 방지와 공유 브라우저 잠금을 유지합니다. API/Firestore 구조 변경 없이 Mac mini 처리기와 CORE 운영규칙만 배포합니다.

공식 근거: 아임웹 주문 모델, API 스키마. isCancelReq는 취소 접수 상태가 아닌 취소 요청 가능 여부이며 실제 취소는 섹션 상태와 환불·결제 상태로 판정합니다.

# 수업 분석 설문과 Notion 구조

## 결정

- Firestore `instructorObservationResponses`를 수업 분석 응답의 원천으로 유지한다.
- Notion `아카이브 온보딩 > 수업 분석 > 수업 분석 기록`은 교육자 검토용 투영 화면으로만 사용한다.
- 설문은 `현장 참가`와 `영상 시청`을 필수로 구분한다.
- Notion 기록은 `수업 대상 강사` 선택 속성으로 저장하고, 해당 속성으로 묶은 보기를 제공한다.
- 중복 키는 작성 강사, 참관 방식, 수업일 또는 분석일, 수업 대상 강사, 수업명과 기구를 사용한다.

## 금지 범위

- Notion 기록을 회원 연락, 예약, 알림톡, 정산 또는 인사평가 자동화의 원천으로 사용하지 않는다.
- 원천 응답을 숨기기 위해 Firestore 기록을 병합하거나 삭제하지 않는다.

## 검증

- API 입력 검증과 참관 방식별 canonical key 분리를 단위 테스트한다.
- 배포 후 현장 참가와 영상 시청이 라이브 설문에 표시되는지 확인한다.
- 합성 제출 1건으로 Firestore 저장과 Notion 속성 투영을 확인한 뒤 테스트 산출물을 정리한다.

# 2026-08-25 주차 입차 조회와 확인필요 메일

## 결정

- 등록 차량의 자동 입차 조회는 수업 시작 30분 후 한 번만 수행한다.
- 입차 기록이 없으면 자동 재조회하지 않는다.
- 작업은 `manual_review / no_entry`로 남기고 `home@archivepilates.com`에 확인필요 메일을 한 번만 발송한다.
- 같은 주차 작업에는 메일 시도 상태를 저장해 중복 발송하지 않는다.
- 메일에는 수업일시, 대상 이름, 차량번호 뒤 4자리, 요청 할인시간, 작업 ID와 ARCHIVE CORE 확인 링크만 포함한다.
- 전체 전화번호와 전체 차량번호는 메일에 노출하지 않는다.

## 운영

- 제목 형식: `[주차등록][확인필요] 입차기록 없음 · YYYY-MM-DD`
- Gmail 라벨: `주차등록 보고`, `자동화 확인필요`
- 메일을 받은 운영자는 ARCHIVE CORE 주차등록에서 입차 여부를 확인하고 필요한 경우 수동 처리한다.
- iParking 자동 재조회는 하지 않으며 운영자의 명시적 수동 확인만 허용한다.
- 메일 전송 자체가 실패해도 자동 재시도하지 않고 ARCHIVE CORE 최근 주차권 작업에 확인메일 실패 상태를 표시한다.

# 아임웹 판매영상 릴리스 표준

## 결정

- 판매영상 메타데이터의 단일 기준은 `config/imweb-paid-video-catalog.json`으로 한다.
- 내 강의실 판매영상 목록과 영상구매 화면의 상품·추천 데이터는 카탈로그에서 생성한다.
- 상품 상세와 등록 초안은 릴리스 입력 JSON 한 번으로 생성한다.
- 전체 유튜브 영상 ID는 Git 추적 파일과 공개 자산에 넣지 않는다.
- 회원그룹 생성과 숨김 시청 페이지의 영상 위젯 연결은 아임웹 공개 API가 지원하지 않으므로 관리자 디자인 모드에서 처리한다.
- 완료 판정은 상품 API, 숨김 페이지 권한, 공개 미리보기, 비로그인 차단, 일반 구매자·비구매자 모바일/PC 검증을 모두 통과한 때로 한다.

## 표준 흐름

1. 원본 영상, 60초 미리보기, 썸네일, 코드, 제목, 강사, 길이, 수업 설명을 확정한다.
   실제 전체 영상 ID가 포함된 입력 파일은 Git 추적 경로가 아닌 `artifacts/imweb-paid-video-release/` 아래에만 둔다.
2. 아임웹에서 `ARCHIVE METHOD {CODE} 40D` 회원그룹을 만들고 그룹 코드를 확인한다.
3. `prepare:imweb-paid-video-release`로 유튜브 전체영상·미리보기 메타데이터, 상품 등록 초안, 상세 HTML, 숨김 페이지 설정 자료를 생성한다. 전체영상은 일부공개, 미리보기는 공개를 기본값으로 한다.
4. `apply:imweb-paid-video-products`로 기존 상품 중복을 먼저 확인하고, 승인된 `--apply` 실행에서 상품을 생성한 뒤 반환된 상품번호를 릴리스 자료에 기록한다.
5. 숨김 시청 페이지를 그룹 전용으로 만들고 전체 영상은 페이지 로컬 영상 위젯에만 연결한다.
6. 생성된 `release-private.json`을 `prepare:imweb-paid-video-release -- --write-catalog`에 전달해 카탈로그, 내 강의실, 영상구매 자산과 런타임 버전을 한 번에 동기화한다.
7. `validate:imweb-paid-video-catalog`과 `verify:imweb-paid-video-release`를 통과시킨다.
8. 배포 후 일반회원 테스트 계정으로 구매자·비구매자 모바일/PC 흐름을 검증하고 임시 그룹을 복구한다.

## 경계

- 생성 도구는 실제 아임웹 상품이나 페이지를 자동 변경하지 않는다.
- `--write-catalog`는 로컬 Git 소스만 갱신하며 외부 서비스 쓰기나 배포를 실행하지 않는다.
- 공개 API에 없는 페이지 위젯 작업을 비공식 요청으로 우회하지 않는다.

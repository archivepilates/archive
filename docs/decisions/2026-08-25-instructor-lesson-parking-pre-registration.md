# 2026-08-25 강사레슨 주차 사전등록

## 목적

- 강사레슨 D-1 알림톡에서 예약자가 수업 당일 이용할 차량을 미리 등록한다.
- 수업 시작 30분 후 아이파킹 입차 조회 1회와 4시간 할인 자동 적용에 연결한다.
- 예약 취소, 다른 수업일, 샘플 링크의 실제 저장과 영구 기본차량 오염을 차단한다.

## 원천과 식별

- 예약 원천: `bookings`의 실제 StudioMate 예약 문서와 `appStatus=reserved`.
- 요청 원천: `instructorLessonParkingPreRegistrations`.
- 차량 원천: `parkingVehicles`. 공개 링크 차량은 `validDate=lessonDate`인 수업일 전용 차량이다.
- 연결 키: 예약자, 수업일, METHOD 관리번호로 만든 안정적인 요청 ID와 HMAC 접근 토큰.
- 같은 관리번호의 두 세션은 모든 예약 ID를 하나의 요청으로 병합한다.

## 보안과 동작

- 알림톡에는 토큰이 포함된 원본 URL 대신 `pk-` 짧은 링크 ID만 전달한다.
- API는 토큰 해시를 timing-safe 방식으로 확인하고 응답에 전체 연락처와 전체 차량번호를 노출하지 않는다.
- 등록과 변경은 첫 수업 시작 20분 후 닫는다.
- 등록 시점과 아이파킹 실행 직전에 예약 상태, 수업일과 시작시각을 다시 확인한다.
- 공개 링크 차량은 회원의 영구 기본차량으로 미러링하지 않는다.
- 스텝 샘플은 실제 저장을 하지 않는 `preview=1` 전용 링크를 사용한다.

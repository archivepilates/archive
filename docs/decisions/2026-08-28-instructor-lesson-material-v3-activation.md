# 2026-08-28 강사레슨 수업자료 알림톡 v3 전환

## 목적

- 강사레슨 D-1 수업자료 안내에 주차 사전등록 버튼을 포함한다.
- 승인된 템플릿과 운영 코드, 샘플 승인 문구, ARCHIVE CORE 운영규칙을 같은 계약으로 맞춘다.

## 원천과 계약

- SOLAPI 채널: `KA01PF260511123407631PSoAflYAVXs`.
- 운영 템플릿: `강사레슨_수업자료 안내 v3` (`KA01TP260825074722212ylmndmsB3V4`).
- 버튼 순서: 수업자료 보기, 수업배정 안내, 방문안내 보기, 주차 사전등록.
- 링크 변수: 날짜별 METHOD `관리번호`와 개인별 `주차링크ID`.
- 예약자 원천과 중복 규칙은 기존 강사레슨 D-1 샘플 승인 흐름을 유지한다.

## 운영 결정

- 신규 강사레슨 수업자료 후보와 샘플·본 발송은 v3만 사용한다.
- v2는 과거 발송 이력 식별에만 남긴다.
- D-1 샘플은 김기효 테스트 수신자에게 1회만 보내고, 본문과 버튼 4개를 확인한 뒤 명시적으로 승인한다.
- 샘플의 주차 프리뷰 링크는 해당 샘플 후보의 실제 수업일과 시작시각으로 매번 생성하며, 차량번호를 입력해도 실제 주차 원천에는 저장하지 않는다.
- 공급자 응답이 불명확하면 자동 재시도하지 않으며 실제 수강자에게는 샘플 승인 전 발송하지 않는다.
- 원천 스냅샷이 오래돼 `blocked_source_stale`이 된 샘플은 발송 증거가 전혀 없고 현재 원천·링크가 모두 정상일 때만 1회 회복한다.

## 검증 기준

- SOLAPI 승인 상태, 채널, 본문, 이미지와 버튼 4개가 운영 계약과 일치한다.
- 수업자료, 수업배정, 방문안내, 주차 프리뷰 링크가 모두 정상 접근된다.
- 주차 프리뷰에 해당 수업일과 시작시각이 표시되고 제출 시 외부 저장 요청이 발생하지 않는다.
- 김기효 샘플 1건의 SOLAPI 성공 응답과 발송 이력을 확인한다.
- Functions와 ARCHIVE CORE 배포 후 라이브 표면에서 v3 코드와 4버튼 규칙을 확인한다.

# 2026-08-24 강사레슨 D-1 샘플 승인 규칙

## 결정

- 샘플 승인 절차는 `instructor_lesson_material` 유형의 강사레슨 D-1 알림톡에만 적용한다.
- 다른 알림톡 자동화와 기존 승인 규칙은 변경하지 않는다.
- D-1 11:30 KST에 지정된 스텝 테스트 수신자에게 실제 본 발송과 동일한 템플릿, 본문, 줄바꿈, 날짜별 링크와 버튼으로 샘플 1건을 발송한다.
- SOLAPI 샘플 성공 기록과 사용자의 명시적 승인이 모두 있어야 D-1 18:00 본 발송을 진행한다.
- 샘플 수신 성공은 승인으로 간주하지 않는다. 승인되지 않으면 본 발송하지 않는다.
- 승인 링크의 GET 요청은 확인 화면만 표시하고 POST 요청만 승인으로 기록한다.
- D-1 17:30 KST에 미승인 또는 실패 상태를 다시 확인해 긴급 메일을 보낸다.

## 발송 전 재검증

- StudioMate의 현재 예약 상태를 다시 조회한다.
- 예약 중인 강사만 포함하고 취소, 대기취소, 결석은 제외한다.
- 정규화한 휴대폰번호와 같은 수업일·관리번호로 중복 제거한다.
- 같은 템플릿과 수업일로 이미 성공 발송된 연락처를 제외한다.
- 수업자료, 수업배정, 방문안내 버튼과 라이브 링크를 확인한다.
- 수업자료는 수업 당일 12:00 KST 공개 상태를 유지한다.
- 승인 뒤 예약자 증감은 18:00 최신 명단에 반영하되 템플릿, 수업일 또는 날짜별 링크가 바뀌면 본 발송을 중단한다.

## 범위와 예외

- 대상 수가 기존 대량 승인 임계값보다 적어도 샘플 승인을 생략하지 않는다.
- 같은 주제가 토요일과 일요일에 열리면 날짜별 명단과 관리번호로 각각 샘플 승인한다.
- 본 발송 결과가 불명확하면 자동 재시도하지 않는다.
- 일반 알림톡 큐는 강사레슨 수업자료 후보를 발송하지 않으며 승인 전용 경로만 최대 1회 시도한다.
